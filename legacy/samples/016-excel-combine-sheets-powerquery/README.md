# 016: 複数のExcelシートを1つの一覧にまとめたい

> **対象：事務職・オフィスワーカー / 所要時間：約20分 / 難しさ：🟡 ちょっと応用**

## こんなときに使えます

月別・支店別など、同じ列構成の表が複数シートに分かれているときに使います。

## 何が便利になりますか？

Power Queryを使い、同じ形式の複数表をまとめて更新できる形にする。

## まず試す方法

各表をExcelテーブルにしてPower Queryへ取り込み、「クエリの追加」で縦方向へまとめます。まず2表だけのコピーで試します。

## 結果の見方

元表を変更して更新したとき、統合表にも変更が反映されれば成功です。

## 自分で試してみよう

### テスト1

同じ3列を持つ2つの小さな表をまとめる。

### テスト2

片方へ1行追加して「すべて更新」で増えるか確認する。

## うまくいかないとき

列名やデータ型が違うと意図しない列が増えます。見出しをそろえてから試します。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

部署別、月別、支店別の定期集計に発展できます。
