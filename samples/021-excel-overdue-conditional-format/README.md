# 021: Excelで期限切れの行だけ自動で目立たせたい

> **対象：事務職・オフィスワーカー / 所要時間：約15分 / 難しさ：🟡 ちょっと応用**

## こんなときに使えます

タスク一覧で、期限を過ぎた未完了だけ見落とさないようにしたいときに使います。

## 何が便利になりますか？

TODAYと条件付き書式で、期限を過ぎて未完了の行を強調する。

## まず試す方法

期限がD列、状態がE列なら条件付き書式の数式に `=AND($D2<>"",$D2<TODAY(),$E2<>"完了")` を設定します。

## 結果の見方

昨日以前の期限で未完了の行だけ指定した色になれば成功です。

## 自分で試してみよう

### テスト1

昨日の日付・未処理の行が強調されるか確認する。

### テスト2

同じ行を完了へ変えて強調が消えるか確認する。

## うまくいかないとき

適用範囲と数式の行番号がずれると、別の行が色付けされます。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

申請期限、契約更新、回答期限、作業管理へ応用できます。
