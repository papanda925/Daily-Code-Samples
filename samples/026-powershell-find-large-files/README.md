# 026: 容量の大きいファイルを探したい

> **対象：事務職・オフィスワーカー / 所要時間：約15分 / 難しさ：🟡 ちょっと応用**

## こんなときに使えます

ディスク容量が減ってきたときに、どのファイルが大きいか確認したいときに使います。

## 何が便利になりますか？

PowerShellでフォルダー内の大きいファイルを上位から確認する。

## まず試す方法

付属スクリプトは指定フォルダーを読み取り、サイズ順に上位ファイルを表示します。削除はしません。

このフォルダーには **`Find-LargeFiles.ps1`** も入っています。最初にコードを読み、テスト用データで試してください。

## 結果の見方

大きいファイルから順に名前・サイズ・場所が表示されれば成功です。

## 自分で試してみよう

### テスト1

テストフォルダーへ大小3ファイルを置き、順番を確認する。

### テスト2

表示件数を5件から10件へ変えて結果件数を確認する。

## うまくいかないとき

大きなフォルダーを再帰検索すると時間がかかります。最初は小さい範囲で試します。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

不要ファイル候補の確認、共有フォルダーの容量調査に使えます。
