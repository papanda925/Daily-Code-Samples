Daily Code / 04

ぼけた画像でOCRが読み違える箇所を探す｜Tesseract.js

帳票を小さい画像にすると、数字を読み違えることがあります。

元の画像と縮小画像を同じOCRエンジンに渡して、どこから誤りが出るか見ます。

ライブデモへ

最初に知っておく用語

OCR
画像内の文字を読み取る処理
認識モデル
読み取りに使う学習済みデータ

象限図で考える

二つの軸で見直す箇所を探します。

点の座標は考え方を示す例です。

図を読み込み中
Mermaidのソースを見る
quadrantChart
    title OCRで確認する優先度の例
    x-axis 小さい文字 --> 大きい文字
    y-axis 低いコントラスト --> 高いコントラスト
    quadrant-1 条件を維持
    quadrant-2 大きさを確認
    quadrant-3 優先して見直す
    quadrant-4 明暗を確認
    縮小した灰色文字: [0.2, 0.25]
    元の黒文字: [0.78, 0.88]

ライブデモ

公開データや検証用のファイルで試してください。

100 と 25 で実行する。

表示された画像と認識結果を比較する。



実装コード
async v=>{const {createWorker}=await lib('tesseract.js@6.0.1');const source=panel('canvas');source.width=360;source.height=85;const c=source.getContext('2d');c.fillStyle='white';c.fillRect(0,0,360,85);c.fillStyle='black';c.font='28px sans-serif';c.fillText('ORDER 1058 / TOTAL 42',12,51);const small=panel('canvas'),ratio=Math.max(8,Math.min(100,Number(v)||25))/100;small.width=360*ratio;small.height=85*ratio;small.getContext('2d').drawImage(source,0,0,small.width,small.height);const w=await createWorker('eng',1,{workerPath:'https://cdn.jsdelivr.net/npm/tesseract.js@6.0.1/dist/worker.min.js'});try{const a=await w.recognize(source),b=await w.recognize(small);say({元画像:a.data.text,縮小画像:b.data.text})}finally{await w.terminate()}}


結果の見方
縮小すると文字の輪郭が弱くなる。
差が出なければ 12 も試す。
結果が空になっても画像の文字が消えたとは限らない。
元画像の結果が正しく読める条件から、一項目ずつ下げる。


コードの要点
英語モデルのワーカーで両方を recognize し、取得した文字列を原文と並べる。


仕事で使うとき
誤読の検証では向きと明るさを固定する。
認識結果は原画像と照合する。
