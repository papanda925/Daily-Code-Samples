# 025: PCの空き容量を数字で確認したい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

Cドライブがどれくらい空いているか、画面だけでなく数字で確認したいときに使います。

## 何が便利になりますか？

PowerShellでドライブの総容量・空き容量・使用率を見やすく確認する。

## まず試す方法

付属スクリプトはローカルディスク情報を読み取り、GB単位で総容量と空き容量を表示します。設定は変更しません。

このフォルダーには **`Get-DiskFreeSpace.ps1`** も入っています。最初にコードを読み、テスト用データで試してください。

## 結果の見方

Cドライブなどの容量と空き容量がGBで表示されれば成功です。

## 自分で試してみよう

### テスト1

エクスプローラーの表示とCドライブ空き容量を比べる。

### テスト2

USBドライブ接続前後で表示対象が変わるか確認する。

## うまくいかないとき

ネットワークドライブや特殊ドライブは取得方法が異なることがあります。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

定期的な容量確認やPC点検チェックに発展できます。
