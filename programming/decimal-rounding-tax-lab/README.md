# Decimalで税額の端数を比較する（架空データ）

Python 3.10以降の標準ライブラリのみ。依存パッケージ・ネットワーク・実ファイル書換えなし。Ubuntu系の隔離Python 3環境で2026-11-16に5テスト成功。Windows/macOSは未実行。

## まず試す

```text
python3 amounts.py
python3 -m unittest discover -p 'test_*.py' -v
```

このコマンドは教材フォルダで実行する。結果は15円→税2円、25円→税3円、0.1円→税0円。数量は1。税率10%は**説明用の架空の計算条件**で、実際の税務・請求ルールの適用を保証しない。

## ここを見る

`Decimal('25') * Decimal('0.10')` は2.50。ROUND_HALF_UPなら税3、ROUND_HALF_EVENなら税2。浮動小数点数から直接Decimalを作らず文字列を使う。丸めは`quantize(Decimal('1'))`で明細単位に行う。

## 1か所変える

`calculate('25', 1, ROUND_HALF_EVEN)` として税が2に変わることを確認。さらに`calculate('15', 2)` は小計30、税3となる。数量を変えると丸め前の金額も変わる。

## 失敗・境界条件

NaN、負数、数字でない文字、数量0、真偽値数量はValueError。価格は0以上の有限Decimalを許可する。小数桁数や上限・通貨単位はこの最小教材では制限しない。大きすぎる桁数・Decimalコンテキストの変更は未検証。例外に秘密の入力値を含めない。

## 仕事で使うなら

税率、端数処理の単位（明細/伝票）、税込/税抜、通貨の最小単位、適用日、返品・割引、法令や社内規程を先に確定する。この教材をそのまま請求計算に使用しない。
