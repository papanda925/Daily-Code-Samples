# 032: Outlookで添付ファイル付きメールだけ探したい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

「あの人から届いたExcel添付メール」のように、受信箱を何度もスクロールして探しているときに使います。

## 何が便利になりますか？

検索条件を使い、差出人や添付有無で目的のメールを絞り込む。

## まず試す方法

Outlookの検索欄で添付ファイルありのフィルターを使います。検索構文が使える環境では `hasattachments:yes` や差出人条件も組み合わせられます。

## 結果の見方

添付ファイル付きのメールだけに絞り込まれれば成功です。

## 自分で試してみよう

### テスト1

添付ありの条件だけで検索する。

### テスト2

特定の差出人条件も追加し、件数が減るか確認する。

## うまくいかないとき

Outlookの新旧バージョンや言語によって検索候補・構文の見え方が異なることがあります。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

件名、期間、差出人、添付条件を組み合わせると探しやすくなります。
