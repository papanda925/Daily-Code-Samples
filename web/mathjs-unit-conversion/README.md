# 混在する寸法の単位をそろえる｜math.js

寸法表にインチとセンチが混ざると、そのままでは比較しづらくなります。両方をミリに変換し、長さ以外が混ざった場合の扱いも見ます。

## 最初に知っておく用語

- **単位変換**は、同じ量を別の単位に直す処理です。
- **次元**は、長さや質量など量の種類です。

## 処理のフローチャートで考える

左から右に読みます。「センチ表記」が変わると「ミリへ換算」にどう影響するかを予想します。

1 in と 2.54 cm を比べる。次は 1 kg を入れる。

### 結果の見方

長さはいずれも25.4 mm。質量は長さへ変換できない。

25.4 mm と 25.4 の違いに注意する。後者だけでは元の単位が分からないので、入力として受け付けるなら既定の単位を明示する。

## コードの要点

math.unit で各値を読み、mm に変換して表示する。

実装はデモ画面の「実装コード」で確認できます。

## 仕事で使うとき

設計データを統合するときは単位も一緒に保存する。
