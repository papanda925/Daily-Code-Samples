# 041: メール添付ファイルをOneDriveへ自動保存したい

> **対象：事務職・オフィスワーカー / 所要時間：約25分 / 難しさ：🟡 ちょっと応用**

## こんなときに使えます

定期的に届く添付ファイルを毎回手でOneDriveへ保存しているときに使います。

## 何が便利になりますか？

Power Automateで受信メールの添付ファイルを決めたフォルダーへ保存する流れを学ぶ。

## まず試す方法

Power Automateでメール受信トリガーを作り、添付ファイルを繰り返し処理してOneDriveの「ファイルの作成」へ渡します。最初は自分宛てのテストメールと専用フォルダーを使います。

## 結果の見方

テストメールを受信した後、指定フォルダーへ添付ファイルが作成されれば成功です。

## 自分で試してみよう

### テスト1

小さなテキストファイル1個を添付して保存されるか確認する。

### テスト2

添付2個のメールで2ファイルとも保存されるか確認する。

## うまくいかないとき

同名ファイル、容量制限、組織のPower Automate利用制限に注意します。本番フォルダーでいきなり試しません。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

差出人や件名で条件を付け、必要なメールだけ保存する流れへ発展できます。
