スマホで縦に読む Papanda Manga Viewer

横向き版と同じ4枚のマンガ画像を、JSONから読み込んで上から順に並べる縦読みサンプルです。ボタンでページを切り替えず、スマホではそのまま下へスクロールして読めます。

横向きページ切り替え版を開く GitHubの説明とソースを見る

マンガデータを読み込み中...

横向き版との違い

横向き版は currentIndex で1ページだけを選んで表示します。縦読み版はJSONの全ページを順番にDOMへ追加します。2ページ目以降の画像には loading="lazy" を指定し、必要になるまで画像読み込みを遅らせます。
