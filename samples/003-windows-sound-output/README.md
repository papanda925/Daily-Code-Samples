# 003: 音が出ないときに出力先を確認したい

> **対象：事務職・PC初心者 / 所要時間：約5分 / 難しさ：🟢 はじめて**

## こんなときに使えます

Teams会議や動画を開いたのに音が出ない、イヤホンを挿したのにPC本体から音が出る、といった場面で使います。

## 何が便利になりますか？

「音が出ない = PCが壊れた」と考える前に、**どこへ音を出す設定になっているか**を自分で確認できます。

HDMI接続したモニター、Bluetoothイヤホン、USBヘッドセットなどを使うと、Windowsには複数の出力先が表示されることがあります。

## まずは画面操作でやってみる

1. タスクバー右下のスピーカー付近をクリックします。
2. 音量が0やミュートになっていないか確認します。
3. 音声の出力先を選べる画面を開きます。
4. PC内蔵スピーカー、イヤホン、モニターなど、目的の機器を選びます。
5. 必要なら「設定 → システム → サウンド」も開きます。

## アプリごとの音量も確認する

Windowsの音量ミキサーでは、アプリごとに音量が異なる場合があります。

「Windows全体の音量は50なのに、ブラウザーだけ0」ということもあります。

## 自分で試してみよう

### テスト1：出力先を確認する

イヤホンや外部モニターを接続している場合、出力先の候補が増えるか確認します。

### テスト2：アプリごとの音量を見る

ブラウザーやTeamsなどを起動した状態で音量ミキサーを開き、アプリごとの設定が見えるか確認します。

## うまくいかないとき

機器自体が一覧に出ない場合は、接続状態、Bluetooth、USBケーブル、ドライバーなど別の原因も考えられます。

会社PCではデバイス利用が制限されていることもあります。

## もう少し便利にする

今後のサンプルでは、PowerShellなどから「PCが認識している音声デバイスの情報を確認する」方法にも発展できます。

まずはGUIで、**音量と出力先は別の設定**だと理解するのがポイントです。
