# 029: Wordでバラバラになった書式をいったん揃えたい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

Webや別文書から貼り付けた文章だけ字体や大きさが違うときに使います。

## 何が便利になりますか？

貼り付けで崩れた文字書式や段落書式をクリアして整え直す。

## まず試す方法

対象文字を選び「すべての書式をクリア」を使います。文字だけなら Ctrl+Space、段落なら Ctrl+Q が役立つ場合もあります。

## 結果の見方

選択部分が標準的な書式へ戻り、周囲と整えやすくなれば成功です。

## 自分で試してみよう

### テスト1

太字・色付きのテスト文章で書式クリアを試す。

### テスト2

段落のインデントを付けてCtrl+Qとの違いを確認する。

## うまくいかないとき

意図的な強調やリンク書式まで消える場合があります。コピーで確認してから使います。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

議事録や報告書の貼り付け後の整形に使えます。
