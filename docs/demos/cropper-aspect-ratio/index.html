写真を用途別の縦横比で切り抜く｜Cropper.js

横長のバナーと正方形のサムネイルでは、同じ写真でも残る範囲が異なります。

枠の比率と位置を変えて見比べます。

ライブデモへ

最初に知っておく用語

縦横比
横幅と高さの比
クロップ
画像の一部を切り出す処理

象限図で考える

二つの軸で用途ごとの構図を比べます。

位置は判断の例です。

図を読み込み中
Mermaidのソースを見る
quadrantChart
    title 構図を決めるときの比較例
    x-axis 縦長 --> 横長
    y-axis 背景を狭く --> 背景を広く
    正方形カード: [0.5, 0.36]
    横長バナー: [0.87, 0.65]
    縦長サムネイル: [0.22, 0.31]

ライブデモ

公開データや検証用のファイルで試してください。

1 と 1.7778 で切り抜く。

枠をドラッグして位置も変える。



実装コード
async v=>{css('https://cdn.jsdelivr.net/npm/cropperjs@1.6.2/dist/cropper.min.css');const {default:C}=await lib('cropperjs@1.6.2');const img=panel('img');img.alt='切り抜き用のサンプル';img.src=svg(480,250,'Example');await img.decode();const cropper=new C(img,{aspectRatio:Number(v)>0?Number(v):1,viewMode:1});button('切り抜く',()=>{const img=panel('img');img.alt='切り抜いた範囲';img.src=cropper.getCroppedCanvas({maxWidth:480,maxHeight:400}).toDataURL();say('切り抜いた結果を表示しました。')});cleanup=()=>cropper.destroy()}


結果の見方
同じ写真でも残る範囲が変わる。
用意した画像では真ん中以外にも文字がある。
枠を中央と左端に動かし、同じ比率でも何が残るか見る。


コードの要点
選択範囲の縦横比を変え、トリミング後の画像を出力する。
利用する版のAPIに合わせる。


仕事で使うとき
サムネイルを作るときは、文字や人物が小画面でも欠けないか見る。
