Daily Code / 50

カードのひな形を複製して別々の内容を入れる｜template

似たカードを追加するたびに画面の構造を書くと、項目が増えたときの修正が大変です。

ひな形を複製し、一枚ずつ内容を入れます。

複製して再利用するひな形
クローン

処理のフローチャートで考える

左から右に読みます。

「複製した要素」が変わると「個別の内容」にどう影響するかを予想します。

図を読み込み中
Mermaidのソースを見る
flowchart LR
    A["カードのひな形"] --> B["複製した要素"] --> C["個別の内容"]

ライブデモ

公開データや検証用のファイルで試してください。

備品Aと備品Bをカンマで並べる。

名前を増やして実行する。



実装コード
v=>{const t=panel('template'),p=el('p',t.content);p.className='card';for(const name of split(v)){const c=t.content.cloneNode(true);c.firstElementChild.textContent=name;scene.append(c)}say(split(v).length+' 枚を複製しました。')}


結果の見方
それぞれのカードに別の名前が入る。
ひな形を追加しただけではカードは表示されない。
複製した内容を画面へ挿入したときに初めて表示される。


コードの要点
template.content を cloneNode(true) で複製し、各名前を textContent で設定する。


仕事で使うとき
複製する中身のIDは重ならないように設計する。
