# 024: たくさんのファイル名の先頭に同じ文字を付けたい

> **対象：事務職・オフィスワーカー / 所要時間：約15分 / 難しさ：🟡 ちょっと応用**

## こんなときに使えます

完了済みファイルへ一括で `完了_` のような文字を付けたいときに使います。

## 何が便利になりますか？

PowerShellのWhatIfで変更予定を確認してから一括リネームする。

## まず試す方法

いきなり変更せず、付属スクリプトを `-WhatIf` 付きで実行して変更予定を確認します。確認後だけ実変更します。

このフォルダーには **`Rename-WithPrefix.ps1`** も入っています。最初にコードを読み、テスト用データで試してください。

## 結果の見方

WhatIfでは実際の名前が変わらず、実行時だけ対象ファイルへ指定プレフィックスが付けば成功です。

## 自分で試してみよう

### テスト1

テスト用3ファイルでWhatIfを実行し、名前が変わらないことを確認する。

### テスト2

コピーしたフォルダーで実変更し、3ファイルに同じ接頭辞が付くか確認する。

## うまくいかないとき

同名ファイルができる場合や、業務フォルダーでの誤実行に注意します。必ずコピーで試します。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

日付や案件番号を先頭へ付ける処理にも応用できます。
