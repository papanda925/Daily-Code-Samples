ライブデモ

公開データや検証用のファイルで試してください。

ブラウザーの幅を600pxの前後で変える。

現在の画像名を見る。



実装コード
()=>{const p=panel('picture'),s=el('source',p),i=el('img',p),wide=svg(550,180,'Full view'),small=svg(300,180,'Close-up');s.media='(min-width: 600px)';s.srcset=wide+' 1x';i.alt='中央にある緑の製品';i.onload=()=>say(i.currentSrc===wide?'全景を表示しています。':'拡大画像を表示しています。');i.src=small}


結果の見方
広い場合は全景。
狭い場合は主役の拡大が選ばれる。
同じ画像を縮める方法と、構図を変える方法では主役の見え方が異なる。
この例は構図の違いを見るために、二つの画像を用意する。


コードの要点
source の media で幅を分け、img.currentSrc を表示する。


仕事で使うとき
画像を切り替えても、同じ目的が伝わる代替テキストを付ける。
