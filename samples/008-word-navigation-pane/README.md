# 008: 長いWord文書で目的の場所へすぐ移動したい

> **対象：Word利用者・事務職 / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

報告書、議事録、マニュアルなどが長くなり、「第5章はどこ？」とスクロールして探しているときに便利です。

## 何が便利になりますか？

Wordの見出しスタイルを使うと、ナビゲーションウィンドウから章や節を一覧で見て、クリックで移動できます。

文字を大きく太字にするだけより、Wordが「ここは見出し」と理解できる形になります。

## まずは画面操作でやってみる

1. 「1. 概要」など見出しにしたい段落を選びます。
2. 「ホーム」タブのスタイルから「見出し1」などを設定します。
3. 「表示」タブからナビゲーションウィンドウを表示します。
4. 左側に見出し一覧が出るか確認します。
5. 見出しをクリックして、その場所へ移動します。

## 自分で試してみよう

### テスト1：見出しを3つ作る

3か所に「見出し1」を設定し、一覧に3つ出るか確認します。

### テスト2：見出し2を入れる

見出し1の下に見出し2を設定し、階層表示になるか確認します。

## うまくいかないとき

文字を太字にしただけではナビゲーションに出ません。スタイルとして「見出し」を設定します。

## もう少し便利にする

見出しを正しく使うと、目次作成、PDFのしおり、文書構造の整理にもつながります。

将来はWord VBAから見出し一覧を取得するサンプルにも発展できます。
