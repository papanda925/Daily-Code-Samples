# 長い手順書で検索語がある場所を強調する｜Mark.js

長い手順書では、検索結果がどの文にあるか見落としやすくなります。探している語だけに色を付けます。

## 最初に知っておく用語

- **強調表示**は、一致した部分の見た目を変えることです。
- **アンマーク**は、前回の強調を取り除くことです。

## 処理のフローチャートで考える

左から右に読みます。「検索語」が変わると「強調箇所」にどう影響するかを予想します。


### 結果の見方

前の強調が消えて新しい語だけが目立つ。

同じ語が一段落に2回あれば2箇所が強調される。以前の装飾を消してから重ねると、検索語の変更が見た目に反映される。

## コードの要点

対象の文書要素に mark を適用し、再検索前に unmark する。

実装はデモ画面の「実装コード」で確認できます。

## 仕事で使うとき

検索結果件数も表示すると、結果がない場合と操作前を区別できる。
