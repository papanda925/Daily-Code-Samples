告知カードをPNGにして共有する｜html-to-image

告知カードをSNSやチャットへ添えるには、画像として取り出せると便利です。

画面のカード部分だけをPNGに変換します。

実装コード
async v=>{const {toPng}=await lib('html-to-image@1.11.13');const card=panel();card.className='card';card.style.width='min(340px,100%)';el('h3',card,v);el('p',card,'点検中は一部の機能を停止します。');const u=await toPng(card,{skipFonts:true});const i=panel('img');i.alt='出力したお知らせカード';i.src=u;const a=el('a',scene,'PNGを保存');a.href=u;a.download='notice.png';say('カードを画像に変換しました。')}


結果の見方
カードだけが画像になる。
出力の対象を親の画面全体に広げると、操作ボタンまで入る。
出力したい範囲を独立した要素にしておく。


コードの要点
toPng の対象をカードだけに限定し、結果を画像として表示する。


仕事で使うとき
素材の配信元が混ざると画像化に失敗することがある。
画像の取得条件を先にそろえる。
