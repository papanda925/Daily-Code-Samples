# Daily-Code-Samples

小さく試せる実用コードを、1日1サンプルを目安に追加していく学習用リポジトリです。

VBA、PowerShell、JavaScript、Python などを対象に、初心者でも「動かして、処理を追って、少し改造できる」ことを重視します。

## このリポジトリの方針

- 1サンプル = 1テーマ
- できるだけ短く、単独で試せるコード
- 初心者向けにコメントを多めに記載
- README に「何ができるか」「処理の流れ」「実行方法」「注意点」を記載
- 大きく育ったテーマは、必要に応じて独立リポジトリへ発展
- papanda925.com の解説記事と連携予定

## 想定する読者

- プログラミングを始めたばかりの方
- VBA や PowerShell を仕事で少し使ってみたい方
- サンプルコードを動かしながら仕組みを理解したい方
- API、ネットワーク、自動化などへ少しずつ学習範囲を広げたい方
