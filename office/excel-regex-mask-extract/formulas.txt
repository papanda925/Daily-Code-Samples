# このサンプルでは、A2セルに次のログ文字列が入っている前提です。
#
# REQ-20260906 user=tanaka@example.com ip=192.168.1.20
#
# REGEXEXTRACT は「条件に合う文字列を取り出す」関数、
# REGEXREPLACE は「条件に合う文字列を別の文字へ置き換える」関数です。
#
# 正規表現は最初は読みにくいので、
# 「何を探しているパターンか」をコメントと見比べながら試してください。


# 1) REQ-20260906 のようなIDを抽出する
#
# [A-Z]{2,10}
#   → 英大文字が2〜10文字続く
#
# -
#   → ハイフンそのもの
#
# [0-9]{4,}
#   → 数字が4文字以上続く
#
# つまり「英大文字-数字」という形を探します。
=REGEXEXTRACT(A2,"[A-Z]{2,10}-[0-9]{4,}")


# 2) メールアドレスの @ より前を *** に置き換える
#
# 1つ目の (...) がローカル部（tanaka）、
# 2つ目の (...) がドメイン部（example.com）です。
#
# 置換後の "***@$2" の $2 は、
# 2番目の括弧で見つかった文字列を再利用する意味です。
#
# そのため、
# tanaka@example.com
#   ↓
# ***@example.com
#
# のように、ドメイン名を残した簡易マスクになります。
=REGEXREPLACE(A2,"([A-Za-z0-9._%+-]+)@([A-Za-z0-9.-]+\.[A-Za-z]{2,})","***@$2")


# 3) IPv4アドレス「らしい」文字列を抽出する
#
# [0-9]{1,3}
#   → 1〜3桁の数字
#
# \.
#   → ドットそのもの
#
# (?: ... ){3}
#   → 「数字 + ドット」のまとまりを3回繰り返す
#
# 最後に数字1〜3桁を付けることで、
# 192.168.1.20 のような形を探します。
#
# 注意:
# この正規表現は「見た目」を確認する簡易版です。
# 999.999.999.999 も一致するため、
# 0〜255の厳密なIPv4検証には使わないでください。
=REGEXEXTRACT(A2,"(?:[0-9]{1,3}\.){3}[0-9]{1,3}")
