ライブデモ

公開データや検証用のファイルで試してください。

1 と 2 で実行する。

英語と日本語の表記を見る。



実装コード
async v=>{const {default:i}=await lib('i18next@24.2.3');const x=i.createInstance();await x.init({lng:'en',resources:{en:{translation:{item_one:'{{count}} item',item_other:'{{count}} items'}},ja:{translation:{item_other:'{{count}}件'}}}});const count=Number(v);say({英語:x.t('item',{count,lng:'en'}),日本語:x.t('item',{count,lng:'ja'})})}


結果の見方
英語は item と items が切り替わる。
日本語は件数が変わる。
この例は英語と日本語を並べる。
言語を追加するときは、0と1と2を実際に試して表示文を確認する。


コードの要点
翻訳キーに count を渡し、英語の単数・複数用リソースを分ける。


仕事で使うとき
翻訳キーは文単位で作る。
単語をつなぐと語順の違う言語に対応しにくい。
