SHA-256は1文字変えるとどうなる？

2つの架空文字列を比べ、64桁のハッシュと256ビット中の差を観察します。外部送信・保存は行いません。

まず試す：「比較する」を押し、下の差分ビット数を見てください。次に右側の文字列を1文字だけ変えます。

SHA-256は暗号化ではありません。入力の秘密やパスワードを入れないでください。結果の差は入力によって変わり、常に128ビット異なるわけではありません。HTTPSまたはlocalhostの安全な環境で動作します。
