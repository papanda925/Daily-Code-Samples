配布資料をフォルダー付きZIPにまとめる｜JSZip

資料を一つのZIPにすると渡しやすくなります。

手順書とデータを別のフォルダーに入れて、受け取った人が迷わない構成にします。

ライブデモへ

最初に知っておく用語

ZIP
複数のファイルをまとめられる形式
相対パス
基準の位置から見たファイルの場所

マインドマップで考える

中心から外へ読みます。

ZIPの中で、資料がどのフォルダーに入るかを示します。

ライブデモ

公開データや検証用のファイルで試してください。

名前を guide/readme.txt にして保存する。

guide を help に変える。



実装コード
async v=>{if(!v||v.includes('..')||v.startsWith('/')||v.includes('\\'))throw Error('安全な相対パスを指定してください');const {default:Z}=await lib('jszip@3.10.1');const z=new Z();z.file(v,'使い方');z.file('data/items.csv','id,name\n1,demo');save('materials.zip',await z.generateAsync({type:'blob'}));say(Object.keys(z.files))}


結果の見方
ZIPを開くと指定したフォルダーが見える。
ファイル名だけをキーにすると、別フォルダーの同名資料を見落とす。
解凍した構造が配布先の案内と合うか確認する。


コードの要点
zip.file('guide/readme.txt', '使い方') と zip.file('data/items.csv', 'id,name') を実行し、generateAsync でZIPを作る。


仕事で使うとき
同名ファイルを区別するときはフォルダー名も渡す。
