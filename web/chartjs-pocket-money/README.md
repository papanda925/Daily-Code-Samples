## まず試す

1. `docs/demos/chartjs-pocket-money/index.html`と`app.js`を同じディレクトリに置く。
2. Pythonが使えるならフォルダの親から `python -m http.server 8000` を起動し `http://localhost:8000/` で開く。
3. 架空の交通費を動かしてグラフと合計を更新する。
4. `SUCCESS` / `RUNNING` / `FAILED` の結果と画面の変化を照合する。現時点では実ブラウザ未検証。

## ここを見る

- [JavaScript本体](../../docs/demos/chartjs-pocket-money/app.js)
- [HTML画面](../../docs/demos/chartjs-pocket-money/index.html)
- ポイント：HTMLのcanvasにChartインスタンスを結び付けます。labelsは横軸に並べる項目名、datasetsは実際の数値や色などの組です。イベントが発生したときにdatasetの一要素だけ変更してchart.updateを呼ぶと、新しいデータが描画へ反映されます。Chart.jsのupdateはインスタンスをまるごと再作成するより単純です。インスタンスを複数回作って既存canvasを使い続けると、意図しない重複や破棄漏れの原因になります。

## 1か所変えてみる

横軸の項目を一つ追加する場合、labelだけ増やして値の配列を増やし忘れると対応関係が崩れます。項目名、値、色の並びが常に対応していることをテストする必要があります。今のデモでは値が入力から直接生成されるため、負数・小数・文字列などの入力は範囲スライダーで制限しています。CSV取り込みなどに拡張するときは、入力の型と件数の検証を先に行ってください。

## 仕事で使うなら

設備の台数、サーバ監視のメトリクス、研修アンケートなど、多数の項目を手早く可視化したい場面に向きます。監視用途では更新時刻・欠測・集計単位・閾値の意味を別に設計しなければなりません。Chart.jsは描画を助けるライブラリであり、集計値の正しさを保証するものではありません。

## 注意点・失敗しやすい点

ゼロと欠測は別物です。0円は「費用がない」という測定値ですが、nullや空欄は「測定できていない」可能性があります。欠測を勝手に0円へ変えると、合計や平均との差が誤解を招きます。また、縦軸の開始位置を途中の値へ変えると小さな差が大きく見えるため、比較の目的と注記が必要です。グラフの画像だけでは読めない人がいるため、数値や合計をHTML本文にも残します。

- 外部CDNは初回読み込み時の通信が必要。オフラインでは動作しない。
