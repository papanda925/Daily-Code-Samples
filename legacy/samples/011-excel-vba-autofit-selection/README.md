# 011: Excelの選択範囲だけ列幅を自動で見やすくしたい

> **対象：Excel利用者・VBAを初めて試す方 / 所要時間：約15分 / 難しさ：🟡 ちょっと応用**

## こんなときに使えます

表を貼り付けたあと、列幅が狭くて「#####」や途中までしか見えない列を、1列ずつ調整しているときに使います。

## まずはGUIでできる方法

Excelでは列見出しの境界をダブルクリックすると、内容に合わせて列幅を自動調整できます。

複数列を選んでから実行すればまとめて調整できます。

## VBAにすると何が違う？

毎回同じ操作をするなら、マクロにしてボタンやショートカットから実行できます。

このサンプルでは、**現在選択している範囲の列だけ**をAutoFitします。

## コピーして試す

標準モジュールへ `AutoFitSelection.bas` のコードを貼り付けます。

実行前に、列幅を調整したいセル範囲を選択します。

## 自分で試してみよう

### テスト1：短い文字と長い文字

A列とB列へ長さの違う文字を入れ、両方を選択して実行します。

### テスト2：選択範囲を変える

A列だけ選んだ場合と、A:Cを選んだ場合で調整される列が変わるか確認します。

## うまくいかないとき

セルではなく図形などを選択していると実行できません。

マクロを使うには、ブック形式や組織のマクロセキュリティ設定にも注意が必要です。

## 注意点

AutoFitすると既存の列幅が変わります。大切な業務ファイルではコピーを使ってテストしてください。

マクロ実行後は通常の「元に戻す」が使えない場合があるため、事前保存・コピーを推奨します。

## こんな自動化にも発展できます

- 全シートの列幅をまとめて整える
- 特定列だけ幅を固定する
- 行の高さも自動調整する
- 書式設定とセットで「表を整えるボタン」にする
