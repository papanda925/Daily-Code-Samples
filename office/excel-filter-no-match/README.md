# Excel FILTERで0件を安全に扱う

## まず試す

A2:B5に次の表を作ります。

| 部署 | 氏名 |
|---|---|
| 営業 | 青木 |
| 総務 | 伊藤 |
| 営業 | 佐藤 |
| 開発 | 高橋 |

D2に検索部署を入れ、E2へ次を入力します。

```excel
=FILTER(A2:B5,A2:A5=D2,"該当なし")
```

## ここを見る

一致行はスピルし、0件なら `#CALC!` ではなく「該当なし」と表示されます。

## 1か所変える

D2を「営業」から「法務」へ変え、0件時の表示を確認します。

## 仕事で使うなら

部署別名簿や未処理一覧で使えます。元範囲に空白や表記ゆれがある場合はTRIM等で正規化してください。

## 注意点

FILTERの利用可否はExcelのバージョン/提供チャネルに依存します。実データでは個人情報の共有範囲にも注意してください。
