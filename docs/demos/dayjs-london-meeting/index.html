深夜の会議を海外拠点の現地時刻に換算する｜Day.js

東京で日付が変わった直後、ロンドンはまだ前日です。

夏と冬で何時間ずれるかを比べます。

公開データや検証用のファイルで試してください。

冬の東京 00:30 を換算する。

日付を 2026-07-15 に変える。



実装コード
async v=>{const [{default:d},{default:u},{default:t}]=await Promise.all([lib('dayjs@1.11.23'),lib('dayjs@1.11.23/plugin/utc'),lib('dayjs@1.11.23/plugin/timezone')]);d.extend(u);d.extend(t);const a=d.tz(v,'Asia/Tokyo');say({東京:a.format('YYYY-MM-DD HH:mm Z'),ロンドン:a.tz('Europe/London').format('YYYY-MM-DD HH:mm Z')})}


結果の見方
ロンドンは冬なら前日15:30。
夏は前日16:30。
東京の時刻には日付も含める。
現地が前日になる案内は、日付と曜日まで表示すると誤読を減らせる。


コードの要点
utc と timezone の両プラグインを読み、dayjs.tz で東京として解釈して Europe/London に変換する。


仕事で使うとき
会議案内には都市名と日付を含める。
時差を年中固定すると夏にずれる。
