# 006: Excelでコードから名前や部署を自動表示したい

> **対象：Excel利用者・事務職 / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

社員番号、商品コード、部署コードなどを入力したら、別の一覧表から名前や部署を自動表示したいときに使います。

## 何が便利になりますか？

毎回マスタ表を見てコピーする作業を減らせます。

入力ミスも減らしやすくなります。

## コピーして試す

A2に検索したい社員番号、別シート「社員一覧」のA列に社員番号、B列に氏名があるとします。

```excel
=XLOOKUP(A2,社員一覧!A:A,社員一覧!B:B,"見つかりません")
```

## 結果の見方

A2の社員番号と一致する氏名が表示されれば成功です。

見つからない場合は「見つかりません」と表示します。

## 自分で試してみよう

### テスト1：存在するコード

社員一覧に存在する番号を入力します。

### テスト2：存在しないコード

存在しない番号を入力し、「見つかりません」と表示されるか確認します。

### テスト3：返す列を変更する

氏名ではなく部署列を指定し、同じ社員番号から部署を表示してみます。

## うまくいかないとき

数字の「123」と文字列の「123」は一致しない場合があります。

コードの前後に空白が含まれていないかも確認します。

## VLOOKUPとの違い

XLOOKUPは「探す列」と「返す列」を個別に指定できます。左側の列を返すこともでき、式を読みやすくしやすいのが特徴です。
