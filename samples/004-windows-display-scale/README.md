# 004: 文字が小さいときに画面を見やすくしたい

> **対象：事務職・PC初心者 / 所要時間：約5分 / 難しさ：🟢 はじめて**

## こんなときに使えます

ノートPCや高解像度モニターで、Excelやブラウザーの文字・ボタンが小さく感じるときに使います。

## 何が便利になりますか？

アプリごとにズームするだけでなく、Windows全体の表示を大きくできます。

ポイントは、**画面の解像度をむやみに下げるのではなく、まず「拡大縮小」を確認すること**です。

## まずは画面操作でやってみる

1. デスクトップを右クリックします。
2. 「ディスプレイ設定」を開きます。
3. 「拡大縮小」を確認します。
4. 100%、125%、150%など、候補から見やすい値を選びます。

Windowsのバージョンにより表示名や場所が少し異なる場合があります。

## 文字だけ大きくしたい場合

Windowsのアクセシビリティ設定には、文字サイズを調整する項目があります。

「ボタンなど画面全体を大きくしたい」のか、「文字を中心に大きくしたい」のかで使い分けます。

## 自分で試してみよう

### テスト1：現在値を覚える

変更前の拡大縮小率をメモします。

### テスト2：1段階だけ変更する

候補を1段階変え、Excelやブラウザーの見え方を確認します。

### テスト3：元に戻す

変更前にメモした値へ戻せることを確認します。

## うまくいかないとき

外部モニターを複数使っている場合、モニターごとに設定が異なることがあります。変更したい画面を選んでから設定します。

## もう少し便利にする

画面設定、解像度、モニター名などの「現在状態を一覧で確認する」方法はPowerShellの題材にもできます。

GUIで設定し、PowerShellで状態を確認する、という組み合わせも便利です。
