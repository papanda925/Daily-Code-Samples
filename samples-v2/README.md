# samples-v2

GitHub-firstブログ用の新しいDaily Code置き場です。

現在は初期状態です。旧 `samples/` からの機械的コピーは行いません。

## 1サンプルの条件

- 元になる `Blog-Ideas/ideas/...md` がある
- 1サンプル = 1目的
- READMEと実コードを置く
- 元ideaのID/パスをメタデータに持つ
- 実行前提と期待結果を短く書く
- 秘密情報・個人情報・環境固有値を含めない
- 実行した場合だけtested/verifiedへ進める
- 記事から直接リンクできる安定したパスにする

## 状態

`planned -> implemented -> tested`

`tested` は実行証拠がある場合だけ使用します。
