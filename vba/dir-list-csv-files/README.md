# VBA Dir関数でCSVファイル名を列挙する

元記事：[Excel VBAのDir関数でファイル一覧を取得](https://github.com/papanda925/Blog-Ideas/blob/main/publish/items/20261016-04-body.md)。この教材は現在のブックを保存したフォルダー直下のCSVファイル名を表示します。ファイルの内容は開かず、変更・削除しません。

## まず試す

1. WindowsのデスクトップExcelで新しいブックを `.xlsm` として練習用フォルダーへ保存。
2. 同じフォルダーにsample-a.csv、sample-b.csv、readme.txtを用意。
3. `ListCsvFiles.bas`を標準モジュールに貼り付け、`ListCsvFiles`を実行してCtrl+Gのイミディエイトに結果を表示。
4. 想定：CSVファイル名2個と件数2が表示。列挙順の固定はしない。（Excel実機未実行）

## ここを見る

`Dir(パターン)`を最初に呼び出し、次は`Dir()`で続きを取得する。途中で別のDir(パターン)を呼ぶと列挙状態が変わり、次の候補を正しく取得できない可能性がある。検索対象は保存済みブックと同じフォルダーの直下。サブフォルダー内までは探索しない。

## 1か所変える

ファイルを1つ除いてCSV件数1になることを確認。次に該当するCSVをすべて除いて、ループに入らず件数0になることを確かめる。空フォルダー自体は例外ではない。

## 仕事で使うなら

- CSVの内容・文字コード・必要列名を別途検査する。拡張子一致だけで取込成功と扱わない。
- 列挙後にファイルが移動する場合もあるので実際に開く直前に存在とアクセス権を確認。
- ファイルの到着完了を判定する処理や安定した順序が必要なら別工程を設ける。
