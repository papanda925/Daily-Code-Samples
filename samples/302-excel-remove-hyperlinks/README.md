# 302: Excelで勝手についたハイパーリンクをまとめて外したい

> **対象：PC初心者・事務職・オフィスワーカー / 所要時間：約15分 / 難しさ：🟡 ちょっと応用**

## このサンプルで体験すること

ExcelへURLやメールアドレスを貼り付けたら、文字が青くなってクリックできる状態になった――という場面を想定します。

このサンプルでは、まずExcelの画面操作で1件だけハイパーリンクを外し、その後、選択範囲にある複数のハイパーリンクをVBAでまとめて外す方法を試します。**ハイパーリンク（クリックするとWebページやメール作成画面などを開くリンク情報）だけを削除し、セルに表示されている文字は残す**のがポイントです。

### こんなときに使える

- URL一覧を資料用の普通の文字列にしたい
- メールアドレスをクリックできない文字として残したい
- コピーした一覧に付いたリンクを一括で外したい
- 1件ずつ右クリックして解除する作業を減らしたい

### 何が便利になるか

- 1件ならGUI、数十件ならVBAと使い分けられる
- 表示文字を残したままリンクだけ外せる
- 選択範囲だけを対象にするため、シート全体を不用意に変更しにくい
- 実行前後のリンク件数を表示して結果を確認できる

## なぜこの方法を使うのか

1件だけなら、Excelの右クリックメニューから解除するのが最も簡単です。

一方、10件、50件と増えると同じ操作の繰り返しになります。そこでVBAを使い、**今選択しているセル範囲だけ**を対象にまとめて解除します。

VBAはExcelの中で繰り返し処理を自動化できる機能です。このサンプルでは、シート全体を変更せず、選択範囲に限定して安全側に寄せます。

## GUIでできる方法

まずは1件だけ画面操作で試します。

1. ハイパーリンクになっているセルを右クリックする
2. **ハイパーリンクの削除** または **ハイパーリンクの解除** を選ぶ
3. 青い下線などの見た目が変わることを確認する
4. セルの文字そのものは残っていることを確認する

Excelのバージョンによってメニュー名が少し異なる場合があります。

## もっと簡単・確実にする方法

複数セルを処理するときは、付属の `Remove-Hyperlinks.bas` を標準モジュールへ貼り付けます。

このマクロは次の順に動きます。

1. 選択範囲にあるハイパーリンク数を数える
2. 0件なら何も変更せず終了する
3. 件数を表示し、実行するか確認する
4. 選択範囲のハイパーリンクだけ削除する
5. 削除後の件数を表示する

## 実行前に確認すること

- **管理者権限：不要**
- **PC設定の変更：なし**
- **Excelブックの変更：あり**（選択範囲のリンク情報を削除）
- **セルの表示文字：原則そのまま残る**
- **VBAの置き場所：標準モジュール**
- **対象：デスクトップ版Excelを想定**
- 実行前にブックを保存するか、テスト用コピーで試す

この処理には自動的な「元に戻す」機能を付けていません。必要なリンクを消してしまった場合に備え、**最初はテスト用ブックまたはコピーで試してください**。

## コピーして試す

1. Excelでテスト用ブックを開く
2. `Alt + F11` でVBAエディターを開く
3. **挿入 → 標準モジュール** を選ぶ
4. `Remove-Hyperlinks.bas` の内容を貼り付ける
5. Excelへ戻る
6. ハイパーリンクを含むセル範囲を選択する
7. `Alt + F8` を押す
8. `RemoveHyperlinksFromSelection` を実行する

最小部分だけ見ると、中心となる処理は次の1行です。

```vb
' Selection は「今、利用者が選択しているセル範囲」です。
' Hyperlinks.Delete は表示文字ではなく、クリック先として保持されているリンク情報を削除します。
Selection.Hyperlinks.Delete
```

実際のサンプルでは、いきなり削除せず件数確認と確認メッセージを加えています。

## コードの流れ

### 1. 選択対象がセル範囲か確認する

VBAでは、図形などを選んでいる場合もあります。そこで `TypeName(Selection) = "Range"` かを確認し、セル以外なら終了します。

### 2. ハイパーリンク件数を数える

`Selection.Hyperlinks.Count` で、選択範囲にいくつリンクがあるかを確認します。

件数が0なら削除処理へ進みません。**変更前に状態を見る**ためのチェックです。

### 3. 利用者へ確認する

削除対象の件数をメッセージで表示し、Yesを選んだときだけ処理します。誤操作を減らすためです。

### 4. 選択範囲だけリンク情報を削除する

`Selection.Hyperlinks.Delete` を使います。

セルの値を `Clear` や `Delete` する処理ではありません。今回削除するのはハイパーリンク情報です。

### 5. 実行後の件数を確認する

削除後にもう一度 `Hyperlinks.Count` を取得します。0件になっていれば、選択範囲のリンク解除は完了です。

## 結果の見方

たとえば選択範囲に5件のリンクがある場合、最初に次のような確認が出ます。

```text
選択範囲に 5 件のハイパーリンクがあります。
リンク情報だけを削除しますか？
```

実行後は次のように表示されます。

```text
処理前: 5 件
処理後: 0 件
```

セルをクリックしてもWebページなどへ移動せず、文字が残っていれば想定どおりです。

## 自分で試してみよう

### テスト1：1件だけで確認する

1. A1へ `https://example.com` と入力する
2. Excelがハイパーリンクにしたことを確認する
3. A1だけ選択してマクロを実行する
4. 処理後が0件になることを確認する
5. A1の文字が残っていることを確認する

**予想結果：** リンクは外れるが `https://example.com` という文字は残る。

### テスト2：リンクあり・なしを混ぜる

1. A1にURL、A2に普通の文字、A3に別のURLを用意する
2. A1:A3を選択する
3. マクロを実行する
4. 処理前が2件、処理後が0件になることを確認する
5. A2の普通の文字が変わっていないことを確認する

**成功判定：** URLの表示文字もA2の文字も残り、クリック可能なリンクだけがなくなる。

## うまくいかないとき

### `マクロを実行できません` と表示される

会社PCではマクロ実行が組織ポリシーで制限されている場合があります。セキュリティ設定を無理に変更せず、GUI方法を使うか管理者へ確認してください。

### リンクが0件と表示される

文字が青く見えても、実際にはセルスタイルだけが残っている場合があります。また、図形に設定されたリンクは今回の対象外です。

### 必要なリンクまで消した

このサンプルはリンク先を記録してから復元する仕組みではありません。保存前ならExcelの「元に戻す」が使える場合がありますが、確実に戻せるよう最初はコピーで試してください。

## 少し便利にする

大量データでは、シート全体ではなく対象列だけを選んで実行すると確認しやすくなります。

また、「すべて削除」ではなく「特定ドメインだけ残す」などの条件を追加することもできます。ただし条件が増えるほど誤削除の可能性も上がるので、まずは選択範囲だけの最小版から使うのがおすすめです。

## 自動化への発展

次のような発展が考えられます。

- 指定した列だけ処理する
- 複数シートを順番に処理する
- 削除前のリンク先を別シートへ一覧保存する
- CSV化する前の前処理としてリンクを外す

実務で全シートを一括処理する場合は、いきなり削除するのではなく、最初に対象件数を一覧化する「確認モード」を作ると安全です。

## 安全性・PCへの変更

- **管理者権限：不要**
- **PC設定の変更：なし**
- **変更対象：現在開いているExcelブックの選択範囲にあるハイパーリンク情報**
- **セル値の削除：なし**
- **Windows設定の変更：なし**
- **戻し方：実行直後ならExcelの「元に戻す」を試す。確実な復元が必要な場合は事前保存またはコピーを使う**

## 仕組みを知りたい人向け

Excelのセルには、表示される値とは別にハイパーリンク情報を持たせることができます。

## 今回触っている技術の層

```text
Excel GUI / VBA
      ↓
Range（セル範囲）
      ↓
Hyperlinks コレクション
      ↓
Excelブック内のリンク情報
```

`Selection` は現在選択中の対象、`Range` はセル範囲、`Hyperlinks` はその範囲に含まれるリンク情報の集まりです。

今回はWebへアクセスする処理ではありません。Excelブック内部に保存されたリンク情報を確認・削除しています。
