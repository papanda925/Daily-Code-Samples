# 012: Excelで重複している値を色で見つけたい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

一覧の中に同じ番号や名前が二重登録されていないか確認したいときに使います。

## 何が便利になりますか？

同じ社員番号や伝票番号が複数ある行を、条件付き書式で見つけやすくする。

## まず試す方法

対象列を選び、条件付き書式の「重複する値」を使うのが最も簡単です。数式ルールなら `=COUNTIF($A:$A,A2)>1` のように判定できます。

## 結果の見方

重複しているセルだけ指定した書式になれば成功です。

## 自分で試してみよう

### テスト1

同じ値を2件入れて両方が強調されるか確認する。

### テスト2

片方を別の値へ変え、強調が消えるか確認する。

## うまくいかないとき

空白も重複として扱いたくない場合は、数式に空白除外条件を加えます。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

社員番号、メールアドレス、請求番号などの重複チェックへ応用できます.
