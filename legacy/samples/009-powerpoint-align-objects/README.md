# 009: PowerPointの図や画像をきれいに揃えたい

> **対象：PowerPoint利用者・事務職 / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

複数の画像や図形を、マウスで少しずつ動かして位置合わせしているときに使います。

## 何が便利になりますか？

PowerPointには、左端・中央・上端などを揃える「整列」と、間隔を同じにする「均等配置」があります。

目測より速く、資料全体を整えやすくなります。

## まずは画面操作でやってみる

1. 同じスライドに図形を3つ作ります。
2. Shiftキーなどを使って複数選択します。
3. 「配置」や「整列」のメニューを開きます。
4. 「上揃え」などを試します。
5. 続けて「左右に整列」「左右に均等配置」などを試します。

Officeのバージョンによりメニュー名や場所が少し異なる場合があります。

## 自分で試してみよう

### テスト1：上端を揃える

高さがバラバラな3つの図形を配置し、上端だけ揃えます。

### テスト2：間隔を揃える

3つ以上の図形を横に並べ、均等配置で間隔が揃うか確認します。

## うまくいかないとき

1つしか選択していないと、複数オブジェクト間の整列はできません。

「スライドに合わせて配置」なのか「選択したオブジェクト同士で配置」なのかも確認します。

## もう少し便利にする

大量のスライドで同じ処理を繰り返す場合は、PowerPoint VBAでサイズ・位置をまとめて揃える方法へ発展できます。
