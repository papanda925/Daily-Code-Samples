Markdownの見出しがどのHTMLになるか見る｜marked

同じ「見出し」という文でも、先頭の記号でページ内の階層が変わります。

変換後のHTMLを観察し、編集した箇所を確かめます。

ライブデモへ

最初に知っておく用語

Markdown
見出しや箇条書きを記号で書く形式
HTML
ページ構造を表す形式

処理のフローチャートで考える

左から右に読みます。

「変換後のHTML」が変わると「表示先」にどう影響するかを予想します。

図を読み込み中
Mermaidのソースを見る

ライブデモ

公開データや検証用のファイルで試してください。

# を ## に変える。

出力タグを見比べる。



実装コード
async v=>{const {marked}=await lib('marked@17.0.5');say(await marked.parse(v))}


結果の見方
h1 が h2 に変わる。
見出しの順番を変えると、ページの構造にも反映される。
HTMLを文字として出すことで、生成結果を一つずつ読み取れる。


コードの要点
marked.parse の出力をプレビュー欄の textContent に入れる。


仕事で使うとき
ユーザーが書いた文をHTMLとして表示する場合は、危険なタグや属性を除く処理を設ける。
