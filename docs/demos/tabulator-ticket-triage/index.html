操作して確かめる

  1. 重要度「高」を選び、表示件数が減ることを確認します。
  2. 検索欄に「ネットワーク」と入れてさらに絞り込みます。
  3. 表の「状態」セルをクリックし、対応中・完了などに変更します。通信も保存もされません。
  4. 「追加」と「戻す」で表示が変わることを確認します。

実務への注意

これは閲覧・入力の練習用です。変更内容はサーバーへ送信されません。ブラウザーを再読込みすると元に戻ります。実システムでは更新の承認、監査証跡、権限、失敗時のロールバックが必要です。
