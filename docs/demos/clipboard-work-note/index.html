整形した作業メモを一操作でコピーする｜Clipboard API

作業メモを毎回選択してコピーする操作は手数がかかります。

ボタンで整形済みの文をコピーし、貼り付けて確かめます。

ライブデモへ

最初に知っておく用語

クリップボード
コピーしたデータを一時的に保持する場所
セキュアコンテキスト
通常はHTTPSやlocalhostで提供される安全な実行環境

ライブデモ

公開データや検証用のファイルで試してください。

コピーを押す。

貼り付け欄で結果を見る。



実装コード
v=>{const p=panel('textarea');p.setAttribute('aria-label','コピー用の整形済み作業メモ');p.readOnly=true;p.value='【作業メモ】\n- '+v;const paste=panel('textarea');paste.setAttribute('aria-label','貼り付けて確認');paste.placeholder='ここに貼り付けて確認';button('コピー',async()=>{try{await navigator.clipboard.writeText(p.value);say('コピーしました。')}catch{p.select();say('選択した文を手動でコピーしてください。')}})}


結果の見方
対応環境では整形済みのメモが貼り付く。
失敗時は手動で選択できる。
操作後は貼り付けた値で結果を確認する。
利用者のクリック直後にコピーを呼ぶと、ブラウザーの操作条件に合わせやすい。


コードの要点
ボタン操作で navigator.clipboard.writeText を呼び、結果を貼り付け欄で確認する。


仕事で使うとき
コピーの成功表示はAPIの処理が完了してから出す。
