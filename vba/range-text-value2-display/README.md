# Excel VBA：Range.Value2とTextの違いを確かめる

[ブログ記事](https://github.com/papanda925/Blog-Ideas/blob/main/publish/items/20261016-03-body.md)

**セルに格納された値（Value2）** と、**現在画面に表示されるテキスト（Text）** を分けて確認する、読み取り専用の教材です。日時、数値の表示形式、列幅、先頭ゼロのあるコードを練習用シートで比較します。Excelデスクトップ版でのVBA利用を想定し、実機実行は未確認です。

## まず試す

1. 新規Excelブックに「表示確認」シートを作る。
2. A2に日時値 `2026/10/16 09:30` を入力し、表示形式を `yyyy/mm/dd hh:mm` にする。単なる文字列ではなくExcelの日時として入力する。
3. B2に数値 `1234.5` を入力し、表示形式を `#,##0.00` にする。
4. C2はあらかじめセルの表示形式を「文字列」にしてから `00123` と入力する。自動変換された123では先頭ゼロの検証にならない。
5. `InspectCellDisplay.bas` のコードをAlt+F11の標準モジュールへ貼り、`InspectDisplayAndValue2` を実行。Ctrl+Gで出力を確認する。

期待される観察（**実機未実行**）：A2のValue2は日時に対応する日付シリアルの数値で、Textは日時の表示文字列。B2のValue2は1234.5、Textは列幅が十分なら「1,234.50」。C2はValue2もTextも文字列「00123」になる想定。日付シリアルの具体値やPCによる表示は実測していない。

## ここを見る

- `Value2` は値の取得・設定ができるVariant。公式によれば、`Value` と異なりCurrencyとDateデータ型を使わず浮動小数点数で返せる。
- `Text` は読み取り専用の**表示形式を適用した文字列**。幅が足りない場合、表示に合わせて「###」などになり得るため、数値計算の入力には適さない。
- `Text` を複数セルRangeで呼ぶと、一部の例外を除いてNullになる場合がある。対象は一セルに限定している。
- 先頭ゼロを「表示形式00000」だけで付ける場合、格納値123とText「00123」は異なる。IDとして扱うなら文字列の正本を決めること。

## 1か所変える

B列の幅を狭くし、B2のTextが画面表示とともに変化するか確かめる。Value2の1234.5は変わらないはず。次にC2を数値123として入力し表示形式を00000に変更すると、Textは00123でもValue2は123の数値になるという差を観察できる。

## 仕事で使うなら

値を計算したいならValue2、画面の見た目を案内したいならTextが候補。ただし、見た目をCSVの正本として書き出すと列幅や地域設定、日付の表示形式の影響を受ける。業務用のファイル変換では、セルの型と出力形式を明示する。先頭ゼロを含むキーを数値化すると復元できない場合がある。
