Daily Code / 52

一時入力の保存範囲を再読み込みと別タブで確認する｜sessionStorage

作業中の入力を再読み込み後も残したい場合があります。

タブを開き直す場合や別タブの場合と比べ、どこまで引き継がれるか確かめます。

ライブデモ

公開データや検証用のファイルで試してください。

メモを保存して再読み込みする。

アドレスを別のタブに直接入力する。



実装コード
v=>{const k='DailyCode52';say(sessionStorage.getItem(k)??'保存した値はありません。');button('保存',()=>{sessionStorage.setItem(k,input.value);say('このタブに保存しました。')});button('削除',()=>{sessionStorage.removeItem(k);say('削除しました。')})}


結果の見方
再読み込みでは残る。
独立した別タブでは通常引き継がれない。
タブを複製した場合は初期値を引き継ぐことがある。
比較用のタブは新しく開き、アドレスを直接入力する。


コードの要点
sessionStorage に保存して再読込し、アドレスを直接入力した別タブでも同じ値があるか確認する。


仕事で使うとき
機密情報や長期保存が必要なデータの置き場にはしない。
