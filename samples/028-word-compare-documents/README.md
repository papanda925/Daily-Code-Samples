# 028: 2つのWord文書の違いを確認したい

> **対象：事務職・オフィスワーカー / 所要時間：約15分 / 難しさ：🟢 はじめて**

## こんなときに使えます

修正版の文書を受け取り、どこが変わったか確認したいときに使います。

## 何が便利になりますか？

Wordの比較機能で修正箇所を見つけ、目視比較の負担を減らす。

## まず試す方法

校閲タブの「比較」から元の文書と変更後の文書を指定します。大切な文書はコピーで試してください。

## 結果の見方

追加・削除・変更が変更履歴のように表示されれば成功です。

## 自分で試してみよう

### テスト1

1文だけ変更した2ファイルを比較する。

### テスト2

段落を1つ削除した版を作り、削除として検出されるか確認する。

## うまくいかないとき

書式変更をどこまで比較するかは比較オプションで変わります。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

契約書、規程、報告書、手順書の改訂確認に使えます。
