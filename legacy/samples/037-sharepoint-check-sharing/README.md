# 037: SharePointのファイルを誰と共有しているか確認したい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

ファイルのリンクを送る前に、誰がアクセスできる状態なのか確認したいときに使います。

## 何が便利になりますか？

アクセスの管理から共有相手・リンクの範囲を確認する。

## まず試す方法

対象ファイルの「アクセスの管理」などから、直接アクセス権と共有リンクを確認します。設定変更はせず、まず読むだけで試します。

## 結果の見方

ユーザー・グループ・共有リンクの範囲を確認できれば成功です。

## 自分で試してみよう

### テスト1

自分だけのテストファイルで現在のアクセス権を確認する。

### テスト2

共有リンクを作成したテストファイルで表示がどう変わるか確認する。

## うまくいかないとき

組織の共有ポリシーにより表示・選択肢が異なります。不要な共有変更はしません。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

外部共有前のセルフチェックや、引継ぎ時の権限確認に役立ちます。
