# Base64は暗号化ではないことをPowerShellで観察する

ダミー文字列をUTF-8→Base64→UTF-8へ往復し、**鍵なしで元に戻る**ことを確認する教材です。

## まず試す

`Show-Base64RoundTrip.ps1` を実行します。実パスワードやトークンは使いません。

## ここを見る

`Original` と `Decoded` が一致すること、途中の `Base64` が読みにくい見た目でも秘密保持にはならないことを確認します。

## 1か所変える

`$text` のダミー文字列だけを変更して再実行します。

## 仕事で使うなら

Basic認証やJWTなどでBase64系表現を見たとき、「読めない文字列＝暗号化」と誤解しないための基礎確認に使えます。

## 注意点

秘密情報を教材へ貼り付けないでください。Base64は可逆なencodingであり、秘密値の保管方法ではありません。
