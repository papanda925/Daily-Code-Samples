## まず試す

[sandbox-demo.sh](sandbox-demo.sh) は、実環境を変更する前に一時ディレクトリだけを用いる考え方を示します。Bashと `mktemp` が必要です。

```bash
bash sandbox-demo.sh
```

**期待結果（未実行）**：一時ディレクトリに`example.txt`が作られ、内容`sample`を表示します。終了時の `trap` でその一時ディレクトリを削除します。

## コードの読みどころ

`mktemp -d` で専用作業場所を作り、`trap 'rm -rf "$tmpdir"' EXIT` で後片付けします。`rm -rf` 自体は破壊的なため、学習用コードでも変数の安全性を確認します。実環境でAIが提案した任意コマンドを**安全だと保証するツールではありません**。
