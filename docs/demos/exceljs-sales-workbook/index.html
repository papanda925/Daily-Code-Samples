売上表をExcelで開ける形にする｜ExcelJS

売上ファイルは、金額がきれいに見えても集計できるとは限りません。

ExcelJSで、売上の表示とセルの値を別々に確かめます。

ライブデモ

公開データや検証用のファイルで試してください。

商品Aの金額を変えて保存する。

1200 と 1200円 を別々に試す。



実装コード
async v=>{const {default:E}=await lib('exceljs@4.4.0/dist/exceljs.min.js');const w=new E.Workbook(),s=w.addWorksheet('売上');const a=v.trim()&&Number.isFinite(Number(v))?Number(v):v;s.addRows([['商品','売上'],['A',a],['B',3500],['合計',{formula:'SUM(B2:B3)',result:(typeof a==='number'?a:0)+3500}]]);s.getColumn(2).numFmt='#,##0';save('sales.xlsx',await w.xlsx.writeBuffer());say({型:typeof a,合計:s.getCell('B4').result})}


結果の見方
数値なら 1,200 と表示できる。
文字列は Excel の SUM で集計から外れる場合がある。
通貨記号を付けたい場合は型を数値に保つ。
金額の記号はセルの表示形式で指定できる。
実ファイルでは合計セルの数式も点検する。


コードの要点
金額列の numFmt を '#,##0' にして workbook.xlsx.writeBuffer() で生成する。


仕事で使うとき
通貨と数値の型を先に決める。
CSVとExcelでは表示形式の扱いも違う。
