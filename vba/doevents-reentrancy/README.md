## まず試す（練習用Excelのみ）

[DoEventsDemo.bas](DoEventsDemo.bas) をExcelの標準モジュールへインポートします。マクロ実行が許可された練習用ブックで、先に `DemoDoEvents` を実行し、次に `LongTask` を実行して比較します。

**期待結果（未実行）**：両方とも500万回のループ中、1万回ごとにExcelのステータスバーへ進捗を表示し、最後は元の標準表示に戻します。所要時間はPC性能に依存します。

## 再入防止の仕組み

`DoEvents` は途中でUIのイベント処理を許すため、**同じマクロを再び起動**してしまう危険があります。`LongTask` はモジュール変数 `mRunning` で同時・再入実行を検出し、実行中ならメッセージを表示して終了します。`DemoDoEvents` にはこのガードがありません。
