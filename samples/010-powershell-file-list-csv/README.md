# 010: フォルダー内のファイル一覧をExcelで見たい

> **対象：事務職・PC初心者 / 所要時間：約15分 / 難しさ：🟡 ちょっと応用**

## こんなときに使えます

共有フォルダーや作業フォルダーに「何のファイルがあるか」を一覧にして、Excelで確認・並べ替えしたいときに使います。

## 何が便利になりますか？

エクスプローラーの画面を見ながら手入力する代わりに、PowerShellへ一覧を作ってもらえます。

ファイル名だけでなく、更新日時やサイズも一緒に出せます。

## まずは1行で試す

```powershell
Get-ChildItem "C:\Temp" -File
```

指定したフォルダーのファイルが表示されます。

## Excelで開けるCSVへ出す

```powershell
Get-ChildItem "C:\Temp" -File | Select-Object Name, LastWriteTime, Length | Export-Csv "C:\Temp\FileList.csv" -NoTypeInformation -Encoding UTF8
```

このフォルダーには、同じ処理を読みやすくした `Export-FileList.ps1` も入れています。

## 自分で試してみよう

### テスト1：テストフォルダーで一覧を作る

3つほどファイルを置き、CSVに3行出るか確認します。

### テスト2：ファイルを1つ増やす

ファイル追加後にもう一度実行し、CSVの件数が増えるか確認します。

## うまくいかないとき

出力先のCSVをExcelで開いたままだと、上書きできない場合があります。

最初は業務共有フォルダーではなく、自分のテスト用フォルダーで試してください。

## こんな自動化にも発展できます

- サブフォルダーも含める
- PDFだけ一覧にする
- 一定期間更新されていないファイルを探す
- 毎朝CSVを自動作成する
