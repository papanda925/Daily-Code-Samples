障害連絡フローの分岐を図にする｜Mermaid

障害が起きたとき、連絡先を手順書から探すと時間がかかります。

重大度の分岐をMermaidで書き、連絡先までの道筋を見せます。

ライブデモへ

最初に知っておく用語

フローチャート
手順や分岐を矢印で示す図
ノード
図の中で作業や判断を表す箱

フローチャートで考える

ひし形は判断を示します。

「はい」と「いいえ」で連絡先が変わります。

図を読み込み中
Mermaidのソースを見る
flowchart TD
    A["障害受付"] --> B{"重大？"}
    B -- "はい" --> C["責任者へ連絡"]
    B -- "いいえ" --> D["担当へ連絡"]

ライブデモ

公開データや検証用のファイルで試してください。

図の「担当へ連絡」を別の文に変える。

軽微の分岐も追加する。



実装コード
async v=>{await drawing(v,panel());say('図を更新しました。')}


結果の見方
入力を変えると連絡経路が描き直される。
連絡すべき人を箱に入れる。
矢印には判断の結果を書く。
重大度の判定基準や連絡先の詳細は本文に置く。


コードの要点
flowchart TD で重大度のノードから二つの矢印を出し、ラベルを付ける。


仕事で使うとき
当番が図を見て連絡先を決められる粒度で書く。
