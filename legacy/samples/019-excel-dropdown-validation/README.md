# 019: Excelで入力候補をプルダウンから選びたい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

「未処理／処理中／完了」のような決まった候補を毎回手入力しているときに使います。

## 何が便利になりますか？

データの入力規則で選択肢を作り、表記ゆれや入力ミスを減らす。

## まず試す方法

候補一覧を別セルへ用意し、対象セルで「データの入力規則」→「リスト」を選び、その範囲を指定します。

## 結果の見方

セルを選ぶと候補が表示され、選んだ文字が入力されれば成功です。

## 自分で試してみよう

### テスト1

3つの状態を候補にして選択できるか確認する。

### テスト2

候補一覧の文字を1つ変更して選択肢へ反映されるか確認する。

## うまくいかないとき

候補範囲へ空白が混ざると空の選択肢が出ることがあります。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

部署名、担当者、区分、申請状態などの標準化に使えます。
