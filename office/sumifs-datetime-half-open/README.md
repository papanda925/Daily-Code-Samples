# Excel SUMIFSで時刻入り売上を日別集計（0時以上・翌日0時未満）

元記事：[SUMIFSで日時のある売上を日別集計](https://github.com/papanda925/Blog-Ideas/blob/main/publish/items/20261016-08-body.md)。

Excelの日付と時刻を扱う関数教材です。入力は架空の数字で、業務データは使用しません。日付のみの完全一致では時刻付き明細を取りこぼすため、**半開区間**を使います。

## まず試す

新しいExcelシートで以下を入力する。A列の日時は文字列ではなく、日付・時刻の数値として認識させる。C列の売上は数値。

| 行 | A列:受注日時 | C列:売上 |
|---|---|---:|
| 2 | 2026/10/15 23:59 | 50 |
| 3 | 2026/10/16 00:00 | 100 |
| 4 | 2026/10/16 09:30 | 200 |
| 5 | 2026/10/16 23:59 | 300 |
| 6 | 2026/10/17 00:00 | 400 |

E2には `2026/10/16` を入力し、F2に`formulas.txt` のSUMIFSの式を入れる。**実機未実行の期待結果は600**。

## ここを見る

- 第一引数C2:C6を合計し、日時範囲A2:A6へ二条件を適用する。
- `">="&E2` は当日0時を含める。`"<"&(E2+1)` は翌日0時を含めない。
- 上限を`<= E2+1`にすると、翌日0時が二重計上される。
- 日時が文字列なら比較が意図どおりにならない場合がある。ExcelのISNUMBER等で元の型を確認する。

## 1か所変える

E2を10/15へ変更したら50、10/17なら400、10/18なら0のはず。終了境界を翌日0時未満から翌日0時以下へ変えると、10/17の売上400が前日に混じる可能性を確認できる。

## 仕事で使うなら

- UTC時刻を日本の日付として集計する場合はタイムゾーン変換を先に行う。
- 数値と文字列の混在、返品によるマイナス、重複取引番号を別途検査する。
- データが増えるなら固定範囲をテーブルの構造化参照などへ変更する。
