背景タブでカウンターを止める｜Page Visibility API

使っていないタブのタイマーを進め続けると、画面を見ていた時間と合わなくなります。

タブが見えていた区間の秒数を足します。

ライブデモへ

最初に知っておく用語

可視状態
ページが画面に見えているかを表す状態
可視時間
見えていた時間の合計

処理のフローチャートで考える

左から右に読みます。

「背景タブ」が変わると「再表示」にどう影響するかを予想します。

図を読み込み中
Mermaidのソースを見る

    A["表示中"] --> B["背景タブ"] --> C["再表示"]

ライブデモ

公開データや検証用のファイルで試してください。

計測を開始し、別タブに移る。

数秒待って戻る。



実装コード
()=>{let sum=0,start=document.hidden?null:performance.now();const update=()=>{if(document.hidden&&start!=null){sum+=performance.now()-start;start=null}else if(!document.hidden&&start==null)start=performance.now()};document.addEventListener('visibilitychange',update);const t=setInterval(()=>say({可視秒:(sum+(start==null?0:performance.now()-start))/1000}),100);cleanup=()=>{clearInterval(t);document.removeEventListener('visibilitychange',update)};say('別のタブへ移って戻ってください。')}


結果の見方
背景にいた時間は表示中の時間に含まれない。
別のタブへ移る直前の秒数を覚える。
戻った直後に値を見て、待った秒数だけ大きく飛んでいないか調べる。


コードの要点
visibilitychange が起きたら document.hidden を読みます。
表示が終わった時点で経過時間を記録します。
戻ったときは別の区間として計測します。


仕事で使うとき
経過時間を測る時計と、表示中だけ進める処理を区別する。
