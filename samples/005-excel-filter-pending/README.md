# 005: Excelで未処理の行だけ別の場所に表示したい

> **対象：Excel利用者・事務職 / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

一覧表の「状態」列に、未処理・処理済みが入っていて、未処理だけを別の場所に自動表示したいときに使います。

## 何が便利になりますか？

通常のフィルターは元の表を絞り込みます。FILTER関数なら、**元表はそのまま残し、条件に合う行だけ別の場所へ表示**できます。

元データが増減すると結果も自動で変わります。

## コピーして試す

A2:D10が一覧表で、D列が状態だとします。

```excel
=FILTER(A2:D10,D2:D10="未処理","対象なし")
```

結果は複数セルへ自動的に広がります。この広がる動きを「スピル」と呼びます。

## 結果の見方

D列が「未処理」の行だけ表示されれば成功です。

該当する行が無い場合は「対象なし」と表示します。

## 自分で試してみよう

### テスト1：処理済みに変える

抽出された行の元データを「処理済み」に変え、抽出結果から消えるか確認します。

### テスト2：未処理を追加する

新しい行を範囲内へ追加し、「未処理」と入力して結果に現れるか確認します。

## うまくいかないとき

結果を表示する範囲に別の文字や数式があると、スピルできないことがあります。結果が広がる場所を空けます。

利用しているExcelのバージョンによってはFILTER関数を使えない場合があります。

## もう少し便利にする

Excelテーブルと組み合わせると、行が増えても範囲を自動追従させやすくなります。

複数条件なら掛け算を使った条件式へ発展できます。
