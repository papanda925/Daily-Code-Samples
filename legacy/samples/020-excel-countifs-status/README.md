# 020: Excelで条件に合う件数だけ数えたい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

「東京支店かつ未処理だけ何件？」のような件数をすぐ出したいときに使います。

## 何が便利になりますか？

COUNTIFSで部署・状態など複数条件に一致する件数を集計する。

## まず試す方法

B列が支店、C列が状態なら `=COUNTIFS(B:B,"東京",C:C,"未処理")` のように複数の条件を並べます。

## 結果の見方

条件に一致した行数と数式結果が同じになれば成功です。

## 自分で試してみよう

### テスト1

東京・未処理を3行作って3になるか確認する。

### テスト2

1行を完了へ変えて2になるか確認する。

## うまくいかないとき

余計な空白や表記ゆれがあると別の値として数えられます。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

問い合わせ件数、申請状況、担当別件数などの簡易集計へ応用できます。
