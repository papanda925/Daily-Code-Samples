# Office Scriptsでテーブル内の文字列を整える

Excelテーブル内の文字列だけを対象に、前後空白、全角スペース、連続空白を整えます。

数式セルは書き換えません。

## 使い方

1. 対象範囲をExcelテーブルにします。
2. Office Scriptsへ `main.ts` を貼り付けます。
3. 実行前にバックアップを取ります。
4. 最初のテーブルを対象に文字列を正規化します。

## まず試す（複製したブックのみ）

[main.ts](main.ts) をOffice Scriptsのコードエディターへ貼り付け、**練習用に複製したExcelブック**で実行します。事前にテーブルを1つ作り、文字列セルへ `  東京　営業  ` のような余分な空白を入れておきます。

**期待結果（未実行）**：文字列の前後空白、全角スペース、連続空白が整理され、`東京 営業` のようになります。実行ログに `文字列を N セル整形しました。` と出ます。数式セル・数値セルは変更しない設計です。

## 実装のポイント

`workbook.getTables()` の**先頭のテーブルだけ**を対象にします。複数テーブルがあるブックでは意図しない対象が選ばれる可能性があるため、実務ではテーブル名を指定します。`getValues()` と `getFormulas()` を比べ、数式を避けて変化した文字列セルだけ `setValue()` します。

## うまく動かないとき・安全・検証
