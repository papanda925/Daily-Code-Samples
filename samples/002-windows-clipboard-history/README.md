# 002: コピーした文字をあとから呼び出したい

> **対象：事務職・PC初心者 / 所要時間：約5分 / 難しさ：🟢 はじめて**

## こんなときに使えます

Excel、メール、Web画面を行き来しながら、何度もコピー＆貼り付けしているときに便利です。

普通の `Ctrl + V` では「最後にコピーした1つ」しか貼り付けられません。Windowsの**クリップボード履歴**を使うと、少し前にコピーした内容も呼び出せます。

## 何が便利になりますか？

たとえば、氏名・電話番号・住所を別々にコピーしたあとでも、順番に呼び出して貼り付けられます。

「さっきコピーした内容を、もう一度コピーし直す」という往復が減ります。

## まずは画面操作でやってみる

1. キーボードで **Windowsキー + V** を押します。
2. 初回は「クリップボードの履歴」を有効にします。
3. メモ帳などで文字をいくつかコピーします。
4. もう一度 **Windowsキー + V** を押します。
5. 貼り付けたい項目をクリックします。

## 結果の見方

履歴の一覧に、直前だけでなく複数のコピー内容が並べば成功です。

よく使う項目はピン留めできる場合があります。

## 自分で試してみよう

### テスト1：3つの文字をコピーする

「東京」「大阪」「名古屋」を順番にコピーし、Windowsキー + V で3つが見えるか確認します。

### テスト2：順番を変えて貼り付ける

最後にコピーしたものではなく、1つ前や2つ前の項目を選んで貼り付けてみます。

### テスト3：通常のCtrl + Vと比べる

`Ctrl + V` と `Windowsキー + V` の違いを確認します。

## うまくいかないとき

Windowsキー + V を押しても履歴が出ない場合は、Windowsの「設定」からクリップボード履歴が無効になっていないか確認します。

会社PCでは組織のポリシーで無効化されている場合があります。

## 注意点

コピーした内容には、パスワードや個人情報などが含まれることがあります。共有PCでは履歴に残したくない情報をコピーしない、不要な履歴を消すなどの配慮が必要です。

## もう少し便利にする

定型文を何度も使う仕事なら、クリップボード履歴だけでなく、Outlookの署名、Wordのクイックパーツ、Power Automateなどへ発展できます。

## 仕組みを知りたい人へ

クリップボードは、コピーした内容をWindowsが一時的に保持する仕組みです。履歴を有効にすると、1件だけでなく複数件を選べるようになります。
