FAQの検索順位をタイトル優先に調整する｜MiniSearch

「パスワードの再設定」を探した人に、本文で触れただけの記事が最初に出ることがあります。

題名の重みを変え、同じ検索語で順位を比べます。

ライブデモ

公開データや検証用のファイルで試してください。

題名の重みを 1 と 5 で比べる。



実装コード
async v=>{const {default:M}=await lib('minisearch@7.1.1');const m=new M({fields:['title','body'],storeFields:['title']});m.addAll([{id:1,title:'account reset',body:'help guide'},{id:2,title:'account guide',body:'reset reset reset'}]);say(m.search('reset',{boost:{title:Number(v)||1}}).map(x=>({題名:x.title,得点:x.score})))}


結果の見方
重くすると題名に reset を含む文書が上がりやすい。
重みは検索全体を変える設定だ。
一件目の順位だけで決めず、よく使う複数の検索語で並びを記録する。


コードの要点
検索対象を title と body にして検索し、boost の title 値を変更する。


仕事で使うとき
毎回同じFAQに誘導したい場合は、重みを変更する前後で複数の検索語を試す。
