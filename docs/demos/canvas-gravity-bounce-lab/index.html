🏀 Canvasで跳ねるボール：重力と反発を比べる

このデモについて

架空のボールを落とし、重力と跳ね返りを変えて動きを観察します。ログイン・外部CDN・APIキーは不要です。

まず試す

①再生 ②反発係数を0.80から0.45へ変更 ③リセットしてもう一度比較。動きを減らす端末設定では、0.2秒ずつ進められます。

Canvasを表示できない場合は数値を参照してください。

教材の範囲

本物の重力加速度を計測するものではありません。画面内のpx単位でモデル化しています。停止可能で、自動再生しません。

原理

落下で速度が増え、床に接触すると速度の向きが反転します。反発係数が小さいほど跳ねる高さは低くなります。
