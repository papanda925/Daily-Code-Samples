選んだ画像のサイズを送信前に見る｜File API

画像を送る前に、利用者へ容量と見た目を知らせると選び直しやすくなります。

ブラウザーでファイルを選び、画像と容量を確認します。

ライブデモへ

最初に知っておく用語

File
ブラウザーが扱うファイル情報
オブジェクトURL
手元のデータを表示するため一時的に発行したURL

処理のフローチャートで考える

左から右に読みます。

「ファイル情報」が変わると「プレビュー」にどう影響するかを予想します。

図を読み込み中
Mermaidのソースを見る
flowchart LR
    A["画像の選択"] --> B["ファイル情報"] --> C["プレビュー"]

ライブデモ

公開データや検証用のファイルで試してください。

別々のダミー画像を選ぶ。

バイト数と表示を比べる。



実装コード
()=>{const q=field('file'),i=panel('img');i.alt='選択した画像';q.accept='image/*';let url;q.onchange=()=>{if(url)URL.revokeObjectURL(url);const f=q.files[0];if(!f){i.removeAttribute('src');return}url=URL.createObjectURL(f);i.src=url;say({ファイル名:f.name,バイト数:f.size})};cleanup=()=>{if(url)URL.revokeObjectURL(url)}}


結果の見方
選び直すと名前と容量と画像が切り替わる。
容量と画像の縦横の大きさは別の情報だ。
送信制限に使うならバイト数を確認する。
画素数の制限は画像の読み取り後に測る。


コードの要点
input.files の最初の File から size と name を読み、必要ならオブジェクトURLでプレビューする。


仕事で使うとき
数値の単位を明記する。
入力制限は送信先でも検証する。
