伝票番号の画面表示と保存値を分ける｜IMask

伝票番号に区切りがあると読みやすくなります。

入力欄にハイフンを表示しながら、保存には数字の並びを使います。

ライブデモ

公開データや検証用のファイルで試してください。

123456 と入力する。

文字や短い番号も試す。



実装コード
async v=>{const {default:I}=await lib('imask@7.6.1');const m=I(field('text'),{mask:'000-000'});const update=()=>say({表示:m.value,保存:m.unmaskedValue});m.unmaskedValue=v;m.on('accept',update);update();cleanup=()=>m.destroy()}


結果の見方
表示は 123-456。
保存値は 123456。
先頭が0の番号も試す。
識別番号を数値へ変換すると先頭の0が落ちるため、保存値は用途に合う型にする。


コードの要点
000-000 のマスクを指定して value と unmaskedValue を表示する。


仕事で使うとき
表示を整えても所定の桁数かは別途検証する。
