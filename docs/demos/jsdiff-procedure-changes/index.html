Daily Code / 10

手順書の変更点を行と文字で見分ける｜jsdiff

手順書を更新すると、元の版との差を共有したくなります。

待ち時間が30秒から45秒に変わった例で、行全体と数字の差を追います。

ライブデモへ

最初に知っておく用語

差分
二つの版で変わった部分
粒度
比較に使う単位の細かさ

Gitグラフで考える

手順書を別の枝で修正し、元の枝へ取り込む例です。

差分を見る起点は「待機30秒」です。

図を読み込み中
Mermaidのソースを見る

ライブデモ

公開データや検証用のファイルで試してください。

区切り線の後の 45 を 60 に変える。

行と文字の出力を見る。



実装コード
async v=>{const d=await lib('diff@8.0.4');const [a,b]=v.split('\n---\n');if(b==null)throw Error('前後の文章を --- の行で区切ってください');for(const [title,compare] of [['行単位',d.diffLines],['文字単位',d.diffChars]]){el('h3',scene,title);const p=panel('pre');for(const x of compare(a,b))el(x.added?'ins':x.removed?'del':'span',p,x.value)}say('追加は下線、削除は取消線で表示します。')}


結果の見方
行差分は変更の場所を示す。
文字差分では数字まで追える。
行が丸ごと強調されたら、次に文字で比べる。
全角と半角の空白も差になるため、意味のある修正かは文脈を読む。


コードの要点
diffLines と diffChars の結果を比較し、added と removed を色で分ける。


仕事で使うとき
手順書の更新では行から先に見る。
締切などの値は文字差分で確認する。
