# Daily Code 原稿60本

Daily-Code-Samplesを取得し、リポジトリのルートから次を実行します。

```sh
python3 -m http.server 8000 --directory docs --bind 127.0.0.1
```

ブラウザーで [実験室](http://127.0.0.1:8000/demos/browser-library-labs/) を開きます。各ページで「実行」を押すと実験できます。一部のライブラリーとMermaidの描画にはインターネット接続が必要です。音声、字幕、共有などはブラウザーや端末の対応状況に依存します。図が描画されない環境でも、各記事に図の読み方とソースがあります。

Markdownをサイトに移す場合は、ライブデモの相対リンクを設置先に合わせてください。Mermaidを表示するには、設置先で対応する描画環境を用意してください。

### 記事40のMSWを使う場合

付属デモでは、すぐに擬似応答を切り替えられます。MSWでブラウザーの通信を受け止める実験もできます。リポジトリのルートで次を実行し、記事40の「MSWで試す（設定後）」を押してください。

```sh
npx --yes msw@2.7.0 init docs/demos/msw-status-response
```

この操作で作る Service Worker は、検証環境にだけ配置します。
