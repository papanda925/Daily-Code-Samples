共有画面へ渡せる端末とコピーで共有する端末を扱う｜Web Share API

端末によっては、ブラウザーから共有先を選ぶ画面を呼び出せます。

使える端末と使えない端末に、それぞれ操作を用意します。

ライブデモへ

最初に知っておく用語

共有シート
端末が表示する共有先の選択画面
フォールバック
ある機能が使えない場合の代わりの操作

分岐のフローチャートで考える

ひし形で「端末の共有機能は使える」を確認します。

結果によって次に進む先が変わります。

図を読み込み中
Mermaidのソースを見る

ライブデモ

公開データや検証用のファイルで試してください。

共有を押す。

選択画面が出た場合はキャンセルも試す。



実装コード
()=>{const u=location.href,p=panel('textarea');p.setAttribute('aria-label','共有用URL');p.readOnly=true;p.value=u;button('共有する',async()=>{try{if(!navigator.share)throw Error();await navigator.share({title:document.title,url:u});say('端末の共有処理に渡しました。')}catch(e){if(e.name==='AbortError')say('共有を取り消しました。');else{p.select();say('選択したURLをコピーしてください。')}}})}


結果の見方
非対応端末では共有URLを選択できる。
選択画面を開いても送信先で受信したとは限らない。
このデモは端末の共有処理へ渡した時点を表示する。


コードの要点
ユーザー操作で navigator.share を呼び、未対応時はURLを表示する。


仕事で使うとき
共有したリンクは受け取る側の端末でも開けるか確認する。
