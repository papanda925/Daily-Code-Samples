# JavaScriptの配列をページ単位で取り出す

検索結果や商品一覧を小分けに表示するために、画面の1始まりのページ番号を配列の0始まりの位置に変換します。5件を2件ずつ切り出す例で、端数と範囲外を観察できます。

## まず試す

Node.js 22系を使用する教材です。外部パッケージやAPIキーは不要です。

1. [pagination.mjs](pagination.mjs) と [pagination.test.mjs](pagination.test.mjs) を同じフォルダに保存する。
2. ターミナルをそのフォルダで開く。
3. `node pagination.mjs` を実行する。
4. `node --test pagination.test.mjs` を実行する。

期待結果：

| ページ | 取り出す要素 |
|---|---|
| 1 | A, B |
| 2 | C, D |
| 3 | E |
| 4 | なし（空配列） |

## 仕組みと変更実験

開始位置は `(page - 1) * size`、終了位置は開始位置 + size。sliceは終了位置を含まないため、ページ間で同じ要素を重複させません。先に最終ページを調べて、範囲外なら空配列を返します。

デモの `pageOf(items, page, 2)` の 2 を 3 に変えると、1ページ目がA,B,C、2ページ目がD,E、残りが空になります。さらに入力配列を空にするとすべて空になります。表示件数を変えるUIでは通常ページ番号も1に戻します。

## うまくいかないとき

| 現象 | 確認 |
|---|---|
| node が見つからない | node --version でNode.jsの導入を確認 |
| ファイルが見つからない | カレントディレクトリと拡張子 .mjs を確認 |
| RangeError | page/size は正の安全な整数。文字列のまま渡さない |
| TypeError | 入力は配列であることを確認 |
| 最終ページが空 | 絞り込みや件数変更後のページ番号を確認 |

sliceは浅いコピーです。結果の配列に追加しても元配列は変わりませんが、含まれるオブジェクトのプロパティを書き換えると元にも影響します。順序を安定させてからページ分割してください。全件を取得済みの小規模一覧向けであり、サーバー側ページングやDBの負荷軽減を保証しません。
