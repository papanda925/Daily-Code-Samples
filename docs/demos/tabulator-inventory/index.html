端末台帳の編集と絞り込みを一画面で行う｜Tabulator

端末台帳で部署を絞り込むと、編集する行を探しやすくなります。

表示を絞ったまま値を編集し、全行表示に戻します。

ライブデモへ

最初に知っておく用語

フィルター
条件に合う行だけを表示する機能
永続化
画面を閉じてもデータを残すこと

ツリーマップで考える

外枠は全端末です。

部署の内側に端末を置きます。

面積の単位は端末1台です。

ライブデモ

公開データや検証用のファイルで試してください。

総務で絞る。

名前のセルを編集する。

条件を空欄にして実行する。



実装コード
async v=>{css('https://cdn.jsdelivr.net/npm/tabulator-tables@6.3.1/dist/css/tabulator.min.css');const {TabulatorFull:T}=await lib('tabulator-tables@6.3.1');const data=[{dept:'総務',name:'端末A'},{dept:'経理',name:'端末B'}],h=panel(),q=field('search');q.value=v;const t=new T(h,{data,layout:'fitColumns',columns:[{title:'部署',field:'dept'},{title:'名前（クリックで編集）',field:'name',editor:'input'}]});const apply=()=>q.value?t.setFilter('dept','=',q.value):t.clearFilter();t.on('tableBuilt',apply);q.oninput=apply;cleanup=()=>t.destroy();say('部署を空欄にすると全行を表示します。')}


結果の見方
条件を解除しても変更した値が見える。
絞り込み中に値を変更すると、表示されている行のデータが変わる。
ページを開き直す前に、保存先の有無を確認する。


コードの要点
列に編集機能を指定し、部署フィルターを切り替える。


仕事で使うとき
同期や保存を追加するまで、編集中の値はこの画面内だけで扱う。
