# 034: Outlookでよく使う返信文をすぐ呼び出したい

> **対象：事務職・オフィスワーカー / 所要時間：約15分 / 難しさ：🟢 はじめて**

## こんなときに使えます

「承知しました」「資料を受領しました」など、同じ返信文を何度も入力するときに使います。

## 何が便利になりますか？

定型文機能を使い、同じ文章を毎回打ち直す作業を減らす。

## まず試す方法

利用しているOutlookに応じて、マイテンプレート、クイックパーツ、署名などの定型文機能を使います。まず短いテスト文を登録します。

## 結果の見方

新しいメールや返信画面で、登録した定型文を数操作で挿入できれば成功です。

## 自分で試してみよう

### テスト1

2行のテスト定型文を登録して呼び出す。

### テスト2

定型文を編集し、次回呼び出し時に変更が反映されるか確認する。

## うまくいかないとき

新しいOutlookとクラシックOutlookでは使える定型文機能が異なります。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

受付返信、資料受領、日程案内、問い合わせ一次回答などに便利です。
