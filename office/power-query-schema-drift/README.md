# Power Query Mで列名ゆれを吸収する

「社員コード」「従業員ID」「社員ID」のように、月ごとに少し違う列名を標準名へ寄せ、必要列が欠けていても `null` で揃えるM関数です。

## 使い方

Power Queryの空のクエリを作り、`NormalizeColumns.pq` を関数として登録します。別クエリから `NormalizeColumns(Source)` のように呼びます。

## ポイント

- 候補列が1つだけなら標準名へ変更
- すでに標準名だけがある場合はそのまま利用
- **同じ意味の候補列が複数同時にあれば、自動で片方を捨てずエラーで停止**
- 最終列は `MissingField.UseNull` で不足列をnull補完
- 列順も固定

## なぜ複数候補で止めるのか

たとえば同じCSVに「社員コード」と「社員ID」の両方が存在し、値が違っていた場合、どちらを採用するかは業務判断です。最初に見つかった列を自動採用すると、もう片方のデータを気付かず落とす可能性があります。

このサンプルでは通常の「列名ゆれ」は吸収しますが、**曖昧な入力はSchemaConflictとして止める**設計にしています。
