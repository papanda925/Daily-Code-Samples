同じ3Dモデルの影の付き方を照明で変える｜three.js

同じ製品でも、光を当てる方向で形の見え方が変わります。

立方体を固定して、光の位置だけを変えます。

実装コード
async v=>{const T=await lib('three@0.174.0');const s=new T.Scene(),c=new T.PerspectiveCamera(38,1.7,.1,100);c.position.set(3,2,4);c.lookAt(0,0,0);const g=new T.BoxGeometry(),m=new T.MeshStandardMaterial({color:0x2ca887});s.add(new T.Mesh(g,m),new T.AmbientLight(0xffffff,.15));const l=new T.DirectionalLight(0xffffff,3);l.position.set(Number(v)||2,2,1);s.add(l);const r=new T.WebGLRenderer({antialias:true});r.setSize(425,250);scene.append(r.domElement);r.render(s,c);cleanup=()=>{g.dispose();m.dispose();r.dispose()};say({照明X:l.position.x})}


結果の見方
左右どちらが明るいかが変わる。
色を比べる面を一つ決める。
光の位置だけを変え、カメラの角度と材質をそろえる。


コードの要点
MeshStandardMaterial と DirectionalLight を使い、カメラと物体の位置を固定して照明だけ移動する。


仕事で使うとき
製品の比較画像はカメラの位置と光量をそろえる。
