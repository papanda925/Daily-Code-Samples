Daily Code / 53

同じサイトの別タブに表示テーマを伝える｜BroadcastChannel

同じサービスを二つのタブで開いた場合に、設定の変更を伝えたいことがあります。

配色のライトとダークをメッセージで送って比べます。

ライブデモへ

最初に知っておく用語

チャネル
メッセージをやり取りする経路
ブロードキャスト
同じ経路を購読する相手に配信すること

アーキテクチャ図で考える

同じ枠の中がメッセージをやり取りする範囲です。

二つのタブが同じ名前のチャネルを開きます。

図を読み込み中
Mermaidのソースを見る
architecture-beta
    group page(cloud)[同一オリジン]
    service a(server)[タブ A] in page
    service bus(server)[共有チャネル] in page
    service b(server)[タブ B] in page
    a:R -- L:bus
    bus:R -- L:b

ライブデモ

公開データや検証用のファイルで試してください。

同じデモを2タブで開く。

片方でテーマ名を送る。



実装コード
()=>{const c=new BroadcastChannel('DailyCode53'),p=panel('p');p.textContent='テーマの見本';p.className='card';const update=x=>{p.style.background=x==='dark'?'#163a31':'#e6f4ed';p.style.color=x==='dark'?'white':'#132821';say('テーマ '+x)};c.onmessage=e=>update(e.data);button('送信',()=>{const x=input.value==='dark'?'dark':'light';update(x);c.postMessage(x)});cleanup=()=>c.close();say('受信待ち。別のタブでも「実行」を押してください。')}


結果の見方
先に開いているタブに配色が伝わる。
送信ボタンを押したタブにも同じ設定を適用する。
相手タブは受信処理で反映する。
後から開いたタブは過去のイベントを受け取らない。


コードの要点
同名のチャネルで postMessage し、受信するタブで配色を変更する。


仕事で使うとき
後から開くタブにも最新値を出す場合は、値を別途保存する。
