# 001: 2つのファイルが本当に同じ内容か確認する

> **対象：PC初心者・事務職 / 所要時間：約5〜10分 / 難しさ：🟢 はじめて**

「同じ名前のファイルが2つあるけれど、本当に同じもの？」

「ダウンロードしたファイルが、配布元のファイルと同じか確認したい」

そんなときに使える小さな便利ワザです。

今回は、Windowsに最初から入っている **PowerShell** を使います。

プログラミングの知識は不要です。まずは1行コピーして試します。

---

## こんな場面で役立ちます

たとえば、こんな経験はありませんか？

- 「最終版.xlsx」と「最終版_本当の最終.xlsx」がある
- 同じ名前のZIPファイルを2回ダウンロードした
- USBメモリへコピーしたファイルが元と同じか心配
- 誰かから「このファイルと同じ？」と聞かれた
- 配布サイトに「SHA-256」という長い文字列が書いてあるが意味が分からない

Windowsのエクスプローラーでは、

- ファイル名
- ファイルサイズ
- 更新日時

などは確認できます。

ただし、それだけでは**中身が完全に同じか**までは分かりません。

そこで使うのが「ファイルの指紋」です。

---

# まず覚えるのはこれだけ

ファイルには、内容から計算できる「指紋」のような値があります。

今回使う **SHA-256** もその一つです。

難しい仕組みは後回しで大丈夫です。

> **同じ内容のファイル → 同じ指紋になる**

まずはこれだけ覚えてください。

---

# まずは画面で確認してみる

PowerShellを使う前に、Windowsのエクスプローラーでも確認してみましょう。

1. 比べたいファイルを右クリック
2. **プロパティ**を開く
3. 「サイズ」と「更新日時」を見る

サイズが違えば、ファイルの中身も違う可能性が高いです。

ただし、

**サイズが同じ = 中身も同じ**

とは限りません。

ここからPowerShellの出番です。

---

# 1行だけ試してみる

## 1. PowerShellを開く

Windowsのスタートメニューを開き、

`PowerShell`

と入力して起動します。

「Windows PowerShell」または「ターミナル」からPowerShellを開けばOKです。

## 2. 次の1行をコピーする

```powershell
Get-FileHash -Path "C:\Temp\sample.txt"
```

`C:\Temp\sample.txt` の部分を、自分が確認したいファイルに変更します。

実行すると、次のような結果が出ます。

```text
Algorithm Hash                                                             Path
--------- ----                                                             ----
SHA256    8A7B...とても長い文字列...                                      C:\Temp\sample.txt
```

見るところは **Hash** の部分です。

これが「ファイルの指紋」です。

---

# 2つのファイルを比べる

たとえば、

```text
C:\Temp\資料A.xlsx
C:\Temp\資料B.xlsx
```

を比べたいとします。

PowerShellで順番に実行します。

```powershell
Get-FileHash -Path "C:\Temp\資料A.xlsx"
Get-FileHash -Path "C:\Temp\資料B.xlsx"
```

## Hashが同じ

```text
資料A.xlsx → ABCDEF123...
資料B.xlsx → ABCDEF123...
```

中身は同じです。

## Hashが違う

```text
資料A.xlsx → ABCDEF123...
資料B.xlsx → 987654XYZ...
```

中身に何らかの違いがあります。

---

# 自分で試してみよう

ここが今回のサンプルで一番大事なところです。

## テスト1：コピーしたファイル

1. メモ帳で `sample.txt` を作る
2. 「こんにちは」と入力して保存
3. ファイルをコピーして `sample-copy.txt` を作る
4. 2つのHashを確認

### 予想

同じHashになるはずです。

---

## テスト2：1文字だけ変更する

`sample-copy.txt` を開いて、

```text
こんにちは
```

を

```text
こんにちは!
```

に変えて保存します。

もう一度Hashを確認します。

### 予想

たった1文字変えただけでも、Hashは大きく変わります。

---

## テスト3：ファイル名だけ変更する

今度は中身を変えず、

`sample.txt`

を

`名前を変えただけ.txt`

へ変更してみます。

### 予想

ファイル名を変えただけなら、中身は同じなのでHashも同じです。

---

# テスト結果を書いてみる

| テスト | 変更したこと | Hashは同じ？ | 分かったこと |
|---|---|:---:|---|
| 1 | ファイルをコピー | □ | |
| 2 | 1文字追加 | □ | |
| 3 | ファイル名だけ変更 | □ | |

実際に試して、自分で結果を埋めてみてください。

---

# もっと簡単に使えるようにしたもの

毎回長いコマンドを書くのが面倒なので、このフォルダには

`Get-FileSha256.ps1`

というサンプルも入れています。

実行例：

```powershell
.\Get-FileSha256.ps1 -Path "C:\Temp\sample.txt"
```

すると、

```text
File      : C:\Temp\sample.txt
Algorithm : SHA256
Hash      : 8A7B...
```

のように必要な情報だけ表示します。

---

# ここが「自動化」の入口

今回PowerShellでやっていることは、特別なハッキングのようなものではありません。

人が画面を開いて1件ずつ確認する代わりに、

**Windows自身に確認させている**

だけです。

たとえば将来は、

- フォルダ内の100個のファイルをまとめて確認
- 昨日と今日で変更されたファイルを探す
- 一覧をCSVやExcelへ出す
- 毎朝自動で確認する

といったことにも発展できます。

これがPowerShellを使う面白さです。

---

# うまくいかないとき

## 「パスが見つかりません」と表示される

ファイルの場所が間違っていないか確認してください。

特に、

```text
C:\Temp\sample.txt
```

のように、ファイル名まで含めて指定します。

## ファイル名に空白がある

パス全体を `"` で囲みます。

```powershell
Get-FileHash -Path "C:\Users\User\Documents\会議 資料.xlsx"
```

## PowerShellを使うのが怖い

今回使う `Get-FileHash` は、ファイルの内容を**読むだけ**です。

ファイルを書き換えたり削除したりするコマンドではありません。

---

# 少しだけ仕組みを知りたい人へ

`Get-FileHash` はPowerShell標準のコマンドです。

今回のスクリプトでは、さらに

- ファイルが本当に存在するか
- フォルダを間違って指定していないか
- 絶対パスはどこか

を確認してからHashを計算しています。

このあたりは「まず使ってみたい」段階では読み飛ばして構いません。

---

# 次に試せそうなこと

- コピー前とコピー後が同じか一括確認する
- ファイル一覧をExcelへ出す
- 更新されたファイルだけ一覧にする
- PowerShellをダブルクリック感覚で使えるようにする
