# 038: 複数のPCやサーバーへ順番にPingして結果をCSVにしたい

> **対象：事務職・オフィスワーカー / 所要時間：約20分 / 難しさ：🟡 ちょっと応用**

## こんなときに使えます

複数ホストの疎通確認を1台ずつ手作業で行っているときに使います。

## 何が便利になりますか？

PowerShellで接続確認を繰り返し、結果をExcelで見られるCSVへ保存する。

## まず試す方法

付属スクリプトへホスト名一覧のテキストファイルを渡し、Test-Connectionの結果をCSVへ保存します。

このフォルダーには **`Test-Hosts.ps1`** も入っています。最初にコードを読み、テスト用データで試してください。

## 結果の見方

ホストごとに到達可否がCSVへ1行ずつ記録されれば成功です。

## 自分で試してみよう

### テスト1

localhostと存在しない名前を2行にして結果の違いを確認する。

### テスト2

3件以上の一覧でCSVの行数が一致するか確認する。

## うまくいかないとき

Pingを許可していない機器は稼働中でも失敗になります。疎通結果だけで障害と断定しません。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

PC点検、機器一覧の一次確認、学習用ネットワークテストへ応用できます。
