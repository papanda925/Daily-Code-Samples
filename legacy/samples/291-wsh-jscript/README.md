# 291: JScript／WSHで簡単なスクリプトを動かして歴史を知る

> **短い実験サンプル / 約10〜20分**

## このサンプルで体験すること
短い実験で「JScript／WSHで簡単なスクリプトを動かして歴史を知る」を体験し、操作前後の状態やログの差を確認する。

## 実行方法
1. `demo.ps1` を読む。
2. 自分のPC・自分のテストデータで実行。
3. 入力や設定を1つだけ変えて再実行し、結果の違いを見る。

## 最小コード
```powershell
Get-Command cscript.exe|Select Name,Source
"WSH JScriptは歴史的なWindows Script Host言語"
```

## 見るポイント
- 文字・ファイル・デバイスが、見た目から型・バイト・APIへどう変換されるか。
- VBAとPowerShellで同じ概念を表したときの添字・型・引数・戻り値の違い。
- 古い仕組みが現在のシステムの基礎としてどこに残っているか。

## 技術の層
```text
Windows標準コマンド / Script → OS機能
```

## 安全性
原則として読み取り・一時ファイル・ダミーデータのみ。実業務の固定長データや認証情報は使いません。全銀関連は教育用の「全銀風」ダミーです。
