# 014: Excelで1つのセルの文字を列ごとに分けたい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

「姓 名」や「部署,氏名,内線」のように、1セルへまとまった文字を分割したいときに使います。

## 何が便利になりますか？

TEXTSPLITを使って氏名や区切り付きデータを複数列へ分ける。

## まず試す方法

半角・全角スペースが混ざる場合は `=TEXTSPLIT(SUBSTITUTE(A2,"　"," ")," ")` のように全角スペースをそろえてから分割します。

## 結果の見方

分割された値が右側の複数セルへ自動的に広がれば成功です。

## 自分で試してみよう

### テスト1

「山田 太郎」を姓と名に分ける。

### テスト2

全角スペースの「山田　太郎」でも同じ結果になるか確認する。

## うまくいかないとき

結果が広がる先に値があるとスピルできません。空いている範囲で試します。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

CSV風の文字列、メールアドレス一覧、部署コードの分解にも使えます。
