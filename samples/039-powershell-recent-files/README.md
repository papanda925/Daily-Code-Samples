# 039: 最近更新されたファイルだけ一覧で確認したい

> **対象：事務職・オフィスワーカー / 所要時間：約15分 / 難しさ：🟡 ちょっと応用**

## こんなときに使えます

「この1週間で変更されたファイルは何？」をフォルダーから確認したいときに使います。

## 何が便利になりますか？

PowerShellで指定日数以内に更新されたファイルを抽出する。

## まず試す方法

付属スクリプトで対象フォルダーと日数を指定すると、更新日時が基準日以降のファイルだけ表示します。読み取りだけです。

このフォルダーには **`Get-RecentFiles.ps1`** も入っています。最初にコードを読み、テスト用データで試してください。

## 結果の見方

最近更新したテストファイルだけが一覧に出れば成功です。

## 自分で試してみよう

### テスト1

今日作ったファイルと古いファイルを置き、7日指定で比較する。

### テスト2

日数を1日と30日に変えて件数が変わるか確認する。

## うまくいかないとき

フォルダーが大きいと再帰検索に時間がかかります。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

引継ぎ、更新漏れ確認、作業実績の補助確認に使えます。
