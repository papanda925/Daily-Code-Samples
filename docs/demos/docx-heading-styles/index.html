手順書の構成をWordファイルに書き出す｜docx

手順書のファイルを自動生成する例です。

見出しに専用のスタイルを割り当て、Wordの見出し一覧で探せる形にします。

ライブデモ

公開データや検証用のファイルで試してください。

ダミー見出しを変えて生成する。

Wordのナビゲーションで確認する。



実装コード
async v=>{const d=await lib('docx@9.2.0');const file=new d.Document({sections:[{children:[new d.Paragraph({text:v,heading:d.HeadingLevel.HEADING_1}),new d.Paragraph('点検結果を記入します。')]}]});save('example.docx',await d.Packer.toBlob(file));say('見出し 1 を指定しました。')}


結果の見方
見出しスタイルを割り当てた行が見出しとして扱われる。
太字と見出しスタイルは文書内で別の役割を持つ。
Wordの見出し一覧で見えるかを比べると、スタイルの効果を確認できる。


コードの要点
Document に見出し段落と行を入れ、ブラウザーなら Packer.toBlob で取得する。


仕事で使うとき
提出用Word文書は指定された提出版を直接ひな形に使う。
ここでは仕組みの説明用にサンプルを生成する。
