## まず試す

1. `docs/demos/p5js-digital-aquarium/index.html`と`app.js`を同じディレクトリに置く。
2. Pythonが使えるならフォルダの親から `python -m http.server 8000` を起動し `http://localhost:8000/` で開く。
3. クリックで魚を増やし、水族館の動きを見る。
4. `SUCCESS` / `RUNNING` / `FAILED` の結果と画面の変化を照合する。現時点では実ブラウザ未検証。

## ここを見る

- [JavaScript本体](../../docs/demos/p5js-digital-aquarium/app.js)
- [HTML画面](../../docs/demos/p5js-digital-aquarium/index.html)
- ポイント：setupは原則最初の準備を一度だけ実行し、drawは描画を繰り返します。魚を表すオブジェクトはx、y、vという位置と速度の値を持ちます。drawでxをvだけ増減させ、次のフレームで別の場所へ描画すると「泳いでいる」ように見えます。translateやscaleを使うと、魚の部品を個別に計算しなくても、図形全体の表示位置や向きを変えられます。pushとpopで変換状態を保存・復元しないと、次の魚まで座標の変換が影響して思わぬ位置に現れます。

## 1か所変えてみる

速度vを負数へ変えると魚が反対側へ泳ぎます。ただし描画した魚の頭の向きがそのままだと、後ろ向きに泳ぐように見えてしまいます。そこでvが負のときscale(-1,1)で左右を反転します。移動速度を2倍にしても魚の大きさは変わりません。今度は楕円のサイズを増やせば大きな魚になります。このように「座標」「速度」「見た目」のパラメータを別々に変え、その効果を確認するのが学習のポイントです。

## 仕事で使うなら

展示、学習教材、イベント会場の動く案内、データに反応するイラストなどへ発展させられます。より実務寄りなら、クリックによる追加を運用イベントに置き換えることもできます。ただし、実際の運用データを公開ブラウザへ載せると情報漏えいにつながることがあります。まずは架空データだけで画面と状態の設計を固めてください。

## 注意点・失敗しやすい点

同じフレームで魚を何千匹も描き始めるとパフォーマンスが落ちます。サンプルは魚の上限を設けます。ブラウザのタブが背面にある間は描画が制限されることがあり、実時間の厳密なシミュレーターにはそのまま使えません。画面のサイズを変更する場合はcanvasの寸法と魚の折返し境界を連動させてください。p5.jsには大きなAPI変更があるため、この教材の使用版は1.x系へ固定し、後から2.x系へ更新するときは互換性を確認します。

- 外部CDNは初回読み込み時の通信が必要。オフラインでは動作しない。
