実装コード（要点）
const label = String(v ?? '').trim().replace(/[&<>"']/g, '').slice(0, 20) || '記録';
const d = driver({ showProgress: true, steps: [
  { element: search, popover: { title: label + 'を検索' } },
  { element: save, popover: { title: label + 'を保存' } }
] });
button('案内を開く', () => d.drive());
cleanup = () => d.destroy();
完全な実装は共通JavaScriptのdemo 35にあります。


結果の見方

終了後に元の操作に戻れるか、マウスだけでなくキーでも試す。


コードの要点
各ボタンを対象とする steps を作り、ガイドを起動する。
