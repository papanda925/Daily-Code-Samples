CPU使用率のグラフと警告しきい値を動かす

7日間の架空CPU使用率を線グラフで示します。スライダーで警告しきい値を動かすと、警告日数と目標線が変わります。

画面を準備しています。

観察すること

しきい値75%なら2日、90%なら1日。クリックするデータがなくても数値で変化を確認できます。

ライブラリはApache 2.0。線グラフの数値を変える実験であり、実サーバー監視ではありません。しきい値は運用SLAとは無関係です。
