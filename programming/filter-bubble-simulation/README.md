# フィルターバブルを単純化してシミュレーションする

推薦モデルの「推定興味」がクリックに寄っていく様子と、**推定に自信が付くほど推薦件数を絞る**という教育用ルールをPowerShellで観察します。

**実際のYouTube、X、Instagram等の推薦アルゴリズムを再現するものではありません。**

## 観察ポイント

- Roundが進むと推定興味が特定方向へ寄る
- この教材では推薦件数を7件から2件へ意図的に段階縮小する
- その結果、表示される候補の幅も狭くなる
- 「パーソナライズ」と「接触する情報の偏り」を分けて考えられる

## なぜ「意図的に絞る」のか

単に「近い5件を出す」だけでは、候補の中心は動いても幅が狭まるとは限りません。
そこで教材では、推薦側の確信度が上がるにつれて候補数を減らすルールを明示的に追加しています。

これは概念を観察するための仮想モデルであり、実サービスの仕様を示すものではありません。

## 検証状態

教育用の独自シミュレーション。実サービスのアルゴリズム検証ではありません。
