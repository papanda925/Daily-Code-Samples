# 017: Excelで数式セルだけ誤って消さないようにしたい

> **対象：事務職・オフィスワーカー / 所要時間：約15分 / 難しさ：🟢 はじめて**

## こんなときに使えます

共有するExcelで、入力欄は触ってよいが計算式は消してほしくないときに使います。

## 何が便利になりますか？

入力セルは編集できるまま、数式セルを保護する基本手順を試す。

## まず試す方法

入力セルのロックを外し、数式セルはロックしたまま「シートの保護」を有効にします。最初はコピーしたブックで試してください。

## 結果の見方

入力セルは編集でき、数式セルを変更しようとすると保護されていれば成功です。

## 自分で試してみよう

### テスト1

入力セルへ文字を入力できるか確認する。

### テスト2

数式セルを削除しようとして保護されるか確認する。

## うまくいかないとき

パスワードを忘れると解除が面倒になります。学習用ではパスワードなしでも仕組みを確認できます。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

入力フォーム、見積書、集計表の誤操作防止へ応用できます。
