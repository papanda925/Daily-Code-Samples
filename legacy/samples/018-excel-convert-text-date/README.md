# 018: Excelで文字列の日付を本当の日付に直したい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

CSVから読み込んだ「2026/09/04」が文字列扱いで、日付計算や並べ替えがうまくいかないときに使います。

## 何が便利になりますか？

DATEVALUEなどを使い、並べ替えや日付計算ができる値へ変換する。

## まず試す方法

Excelが解釈できる形式なら `=DATEVALUE(A2)` を試し、セルの表示形式を日付にします。GUIの「区切り位置」で変換できる場合もあります。

## 結果の見方

値を1日足して翌日になる、日付順に並べ替えできる、といった動作になれば成功です。

## 自分で試してみよう

### テスト1

文字列日付をDATEVALUEで変換する。

### テスト2

変換した値に `+1` して翌日になるか確認する。

## うまくいかないとき

地域設定や `20260904` のような形式では別の分解が必要になることがあります。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

CSV取り込み、勤怠、売上データの前処理へ応用できます。
