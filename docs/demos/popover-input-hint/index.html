Daily Code / 42

入力を続けながら補足ヘルプを表示する｜popover

申請理由を書くときに、入力例を少しだけ見たいことがあります。

入力欄の脇に補足を出し、書きかけの内容を保てるか試します。

ライブデモへ

最初に知っておく用語

ポップオーバー
画面の上に出る小さな補足表示
ライトディスミス
外側を操作すると閉じる仕組み

処理のフローチャートで考える

左から右に読みます。

「補足の表示」が変わると「入力の継続」にどう影響するかを予想します。

図を読み込み中
Mermaidのソースを見る
flowchart LR
    A["編集中の欄"] --> B["補足の表示"] --> C["入力の継続"]

ライブデモ

公開データや検証用のファイルで試してください。

入力欄に文字を書く。

入力例を開いて外側をクリックする。



実装コード
()=>{const q=field('text'),p=panel();p.id='hint';p.setAttribute('popover','auto');p.textContent='例：備品 A を返却する。';const b=button('入力例',()=>{});b.setAttribute('popovertarget','hint');q.oninput=()=>say(q.value)}


結果の見方
補足が閉じても入力内容は残る。
入力例を開いたまま文字を入力できる。
入力中に読ませたい短い補足なら、画面をロックする確認用の部品と使い分けやすい。


コードの要点
popover を付けた要素を popovertarget ボタンで開き、外側をクリックする。


仕事で使うとき
短い入力例に向いている。
必読事項は本文にも残す。
