# Ubuntu → WordPress 自動連携\n\n14:00の既存ブログ枠をDaily Code専用に置き換えるための連携コードです。\n\n処理は GitHub pull → 未記事化サンプル検出 → README/ソースから記事Markdown生成 → new_gemini_postbot の gutenberg_serializer.py でWordPress向けに変換 → WP-CLIで公開 → permalink取得 → GitHub READMEへ記事URLを書き戻し → git commit/push の順です。\n\n二重投稿防止状態は /home/papanda925/new_gemini_postbot/state/daily_code_wordpress.json に保存します。WordPress公開後にGitHub pushだけ失敗した場合、次回は再投稿せず書き戻しだけ再試行します。\n\n初回は Ubuntu で次を実行します。\n\n    cd ~/Daily-Code-Samples\n    git pull origin main\n    chmod +x automation/ubuntu/*.sh\n    ./automation/ubuntu/install.sh\n\ninstall.sh は最初に --dry-run を行い、その後 systemd drop-in で14:00だけ Daily Code に分岐させます。その他9枠は既存 tools/production_dispatcher.py をそのまま実行します。\n\nロールバックは /etc/systemd/system/gemini_postbot_auto_post.service.d/daily-code.conf を削除して daemon-reload すれば戻せます。\n
