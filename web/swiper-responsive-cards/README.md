# 商品カードの表示枚数を画面幅で変える｜Swiper

商品一覧は、狭い画面では一枚ずつのほうが見やすい場合があります。同じカード列を、幅の条件で一枚表示と三枚表示に切り替えます。

## 最初に知っておく用語

- **ブレークポイント**は、表示を切り替える幅の境界です。
- **スライド**は、横へ切り替えられる項目です。

## 処理のフローチャートで考える

左から右に読みます。「切替幅」が変わると「商品カード」にどう影響するかを予想します。

幅を 500 と 800 にする。見えるカードの枚数を数える。

### 結果の見方

768 未満は1枚。768 以上は3枚。

デモが使う幅はカードの領域。ページ全体の幅と同じとは限らない。クリップされる狭い画面では、横にスクロールして実験を観察できる。

## コードの要点

breakpoints で幅768以上の slidesPerView を3にする。

実装はデモ画面の「実装コード」で確認できます。
