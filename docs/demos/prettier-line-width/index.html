同じコードを異なる行幅で整形する｜Prettier

引数が増えると、同じJavaScriptが一行に収まりにくくなります。

Prettierの二つの設定で、そのコードをどこで改行するか見比べます。

同じコードを二系統に分けます。

結果の違いを、設定した行幅に結び付けて読めます。

コードをそのまま実行する。

引数を一つ増やして差を確認する。



実装コード
async v=>{const [p,b,e]=await Promise.all([lib('prettier@3.5.3/standalone'),lib('prettier@3.5.3/plugins/babel'),lib('prettier@3.5.3/plugins/estree')]);say((await Promise.all([40,100].map(async printWidth=>'行幅 '+printWidth+'\n'+await p.format(v,{parser:'babel',plugins:[b.default,e.default],printWidth})))).join('\n'))}


結果の見方
40 のほうが複数行に分かれやすい。
行幅は改行の判断に使う目安。
長い文字列などは設定値を超えることがある。
差が出なければ、引数を増やして試す。


コードの要点
JavaScriptのパーサーを指定して format し、printWidth を40と100で切り替える。


仕事で使うとき
チームで整形設定を共有すると、レビューで変更内容を追いやすくなる。
