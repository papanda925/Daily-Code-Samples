3D曲面の高さを変えるWebGLグラフ

5×5の架空測定値を3D曲面に表示し、高さ倍率を1〜3倍へ動かします。マウスで回転・ズームして形状を観察できます。

画面を準備しています。

観察すること

倍率1では最大高さ16、倍率3では最大高さ48。面の高さは変わるが格子点の数は25のままです。

WebGLに対応するブラウザーとGPU環境が必要です。動きの軽減設定、モバイル性能、WebGL不可環境でのフォールバックは別途検証します。
