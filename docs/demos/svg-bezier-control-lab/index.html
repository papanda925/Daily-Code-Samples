SVGで線の形を変える：ベジェ曲線の操作実験

2つのスライダーで制御点を上下させると、架空のルートの曲がり方が変わります。ログイン・位置情報・外部ライブラリは不要です。

まず動かす

①上側のスライダーを動かす → ②線と数値を見る → ③「直線にする」を押す。
