## まず試す

1. `docs/demos/d3js-vote-bubbles/index.html`と`app.js`を同じディレクトリに置く。
2. Pythonが使えるならフォルダの親から `python -m http.server 8000` を起動し `http://localhost:8000/` で開く。
3. 動物へ投票するたびに円の大きさと票数を変更する。
4. `SUCCESS` / `RUNNING` / `FAILED` の結果と画面の変化を照合する。現時点では実ブラウザ未検証。

## ここを見る

- [JavaScript本体](../../docs/demos/d3js-vote-bubbles/app.js)
- [HTML画面](../../docs/demos/d3js-vote-bubbles/index.html)
- ポイント：D3のselectはDOM要素を対象にし、dataは各要素とデータを結び付けます。joinは表示対象の数が変わったときに、要素を新規作成・更新・削除する方法をまとめて扱えます。SVGはHTMLに埋め込めるベクター形式なので、円とテキストをそれぞれ要素として持てます。今回の円の半径は投票数をそのまま掛け算するのではなく、scaleSqrtで平方根スケールへ変換します。円の面積は半径の二乗に比例するため、半径を数値へ比例させると量の差を過大に見せるからです。

## 1か所変えてみる

色を動物ごとに変えた場合でも、色だけで判断させず名前を表示します。SVGへ棒グラフを追加するなら、同じdata配列を使って複数の表示形式を作れます。transitionの長さを0にすると瞬時に更新されますが、値の大小そのものは変わりません。見せ方を変えるときにデータ処理まで変えてしまわないよう、値の更新関数と描画関数を分離します。

## 仕事で使うなら

アンケート結果、カテゴリの構成、教育教材、展示物などに使えます。実際の選挙や公式集計のような用途では、表示前の票数集計・監査・署名・改ざん防止を別に実装しなければなりません。D3は見せ方のライブラリであり、投票の公正性を保証するものではありません。

## 注意点・失敗しやすい点

円の数が多すぎる場合、ラベル同士が重なって読めなくなります。また、円の面積を適切に調整しても、散らばった円だけでは正確な順位が比較しにくいことがあります。順序が重要なら棒グラフの方が向く場合もあります。さらに、transitionの途中で何度も更新が起きることを前提にして、描画の整合性を確認する必要があります。今回のデモは投票を保存しないため、再読み込みで初期値に戻ります。

- 外部CDNは初回読み込み時の通信が必要。オフラインでは動作しない。
