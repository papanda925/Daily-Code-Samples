業務フローの差し戻し経路を保存する｜bpmn-js

申請を差し戻す場合は、誰が手順をやり直すか示す必要があります。

二つの箱を結び、図を保存してから戻り先を確かめます。

ライブデモへ

最初に知っておく用語

BPMN
業務手順を共通の記号で表す規格
XML
要素と属性でデータを表す形式

フローチャートで考える

確認から申請に戻る矢印を探します。

フォームの記入者に何が戻るかを検討できます。

図を読み込み中
Mermaidのソースを見る
flowchart TD
    A["申請"] --> B["確認"]
    B -- "差し戻し" --> A
    B -- "承認" --> C["完了"]

ライブデモ

公開データや検証用のファイルで試してください。

図の「申請」をダブルクリックして編集する。

保存・再読込を押す。



実装コード
async()=>{css('https://cdn.jsdelivr.net/npm/bpmn-js@18.3.1/dist/assets/diagram-js.css');css('https://cdn.jsdelivr.net/npm/bpmn-js@18.3.1/dist/assets/bpmn-font/css/bpmn.css');const {default:M}=await lib('bpmn-js@18.3.1/lib/Modeler');const h=panel();h.style.height='300px';const m=new M({container:h});await m.createDiagram();const f=m.get('elementFactory'),model=m.get('modeling'),root=m.get('canvas').getRootElement();const s=m.get('elementRegistry').getAll().find(x=>x.type==='bpmn:StartEvent');const a=model.appendShape(s,f.createShape({type:'bpmn:Task'}),{x:290,y:140},root),b=model.appendShape(a,f.createShape({type:'bpmn:Task'}),{x:490,y:140},root);model.updateLabel(a,'申請');model.updateLabel(b,'確認');model.updateLabel(model.connect(b,a),'差し戻し');m.get('canvas').zoom('fit-viewport');button('保存・再読込',async()=>{const {xml}=await m.saveXML({format:true});await m.importXML(xml);m.get('canvas').zoom('fit-viewport');say(xml)});cleanup=()=>m.destroy()}


結果の見方
名前と差し戻し経路が復元される。
差し戻しの線がどこに戻るか確認する。
図を保存して開き直した後も、戻り先とラベルが維持されるかを見る。


コードの要点
saveXML で編集中の図を XML に変えます。
importXML で読み込み直し、図の表示と書き出した結果を確認します。


仕事で使うとき
保存ファイルを受け取る担当者と、使う記号の範囲をそろえる。
