初めて使う画面の操作手順を順番に示す｜Driver.js

初めて使う画面では、ボタンの場所が分かるだけでも迷いが減ります。

検索と保存を順番に案内し、途中で閉じたときの動作を見ます。

ライブデモ

公開データや検証用のファイルで試してください。

案内を開始する。

途中で閉じて画面のボタンを押す。



実装コード
async()=>{css('https://cdn.jsdelivr.net/npm/driver.js@1.3.6/dist/driver.css');const {driver}=await lib('driver.js@1.3.6');const a=button('検索',()=>say('検索を選びました。')),b=button('保存',()=>say('保存を選びました。'));const d=driver({showProgress:true,nextBtnText:'次へ',prevBtnText:'戻る',doneBtnText:'完了',steps:[{element:a,popover:{title:'検索',description:'対象の記録を探します。'}},{element:b,popover:{title:'保存',description:'変更した記録を保存します。'}}]});button('案内を開く',()=>d.drive());cleanup=()=>d.destroy()}


結果の見方
操作の順番を確認できる。
閉じてもボタンは使える。
ガイドが示すボタン名と実際の画面をそろえる。
終了後に元の操作に戻れるか、マウスだけでなくキーでも試す。


コードの要点
各ボタンを対象とする steps を作り、ガイドを起動する。


仕事で使うとき
ガイドを毎回開くと慣れた利用者の邪魔になる。
任意に呼び出せるようにする。
