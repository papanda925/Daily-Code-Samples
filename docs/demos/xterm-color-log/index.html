端末の色付きログの仕組みを確かめる｜xterm.js

端末の色付きログには、画面に出ない命令が含まれます。

赤を開始する命令と、色を元に戻す命令を分けて観察します。

ライブデモへ

最初に知っておく用語

制御シーケンス
端末の表示を操作する文字の並び
リセット
色などを初期状態へ戻す命令

パケット図で考える

一続きのバイト列を区間で見ます。

図の範囲はビット番号です。

色の解除を外すと、次の文字まで赤になります。

図を読み込み中
Mermaidのソースを見る
packet-beta
    0-39: "ESC[31m 赤を開始"
    40-79: "ERROR"
    80-111: "ESC[0m 色を解除"
    112-135: "空白とOK"

ライブデモ

公開データや検証用のファイルで試してください。

on と off で実行する。

OK の色を見る。



実装コード
async v=>{css('https://cdn.jsdelivr.net/npm/@xterm/xterm@5.5.0/css/xterm.css');const {Terminal}=await lib('@xterm/xterm@5.5.0');const t=new Terminal({rows:3,cols:32,disableStdin:true});t.open(panel());const s='\x1b[31mERROR'+(v==='off'?'':'\x1b[0m')+' OK';t.write(s);cleanup=()=>t.dispose();say(JSON.stringify(s))}


結果の見方
解除を送らなければ OK にも赤が残る。
端末に渡される ESC は目に見えない文字だ。
結果欄にはエスケープ表記が出る。
赤色の指示と解除の間にどの文字があるかを見る。


コードの要点
Terminal.write の結果と、制御文字を見える形にした文字列を並べる。


仕事で使うとき
ログ保存時は画面用の色と記録内容を分ける。
