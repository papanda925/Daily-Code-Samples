共有写真に位置情報があるか確認する｜ExifReader

写真によっては、見た目から分からない撮影位置が記録されています。

テスト画像を使い、GPS関連のタグがあるか調べます。

ライブデモへ

最初に知っておく用語

Exif
写真に付随する撮影情報
GPSタグ
位置に関する付加情報

分岐のフローチャートで考える

ひし形で「GPSタグを検出した」を確認します。

結果によって次に進む先が変わります。

図を読み込み中
Mermaidのソースを見る
flowchart TD
    A["画像を読み取る"] --> B{"GPSタグを検出した？"}
    B -- "はい" --> C["位置情報ありと表示"]
    B -- "いいえ" --> D["位置タグの検出なしと表示"]

ライブデモ

公開データや検証用のファイルで試してください。

テスト写真を選ぶ。

GPSを記録しない写真でも試す。



実装コード
async()=>{const {default:E}=await lib('exifreader@4.27.0');const f=field('file');f.accept='image/*';f.onchange=async()=>{try{const a=f.files[0];if(!a)return;const tags=E.load(await a.arrayBuffer());say(Object.keys(tags).some(k=>/^GPS/i.test(k))?'GPS関連タグあり':'GPS関連タグを検出できませんでした')}catch(e){say(e.message)}}}


結果の見方
GPS関連タグがあれば警告が出る。
このデモは値そのものを表示しない。
自分で用意した検証用の画像を使い、公開予定の写真は位置以外の写り込みも別に確認する。


コードの要点
ExifReader.load の結果からGPS関連タグの有無だけを表示する。


仕事で使うとき
タグの表示がない場合でも、写り込みや別形式の位置情報を確認する。
