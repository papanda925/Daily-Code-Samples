実装コード
async v=>{const {default:M}=await lib('mark.js@8.11.1');const p=panel();p.textContent='変更を保存する。控えを確認する。最後に保存先を確認する。';const q=field('search');q.value=v;const m=new M(p);const update=()=>m.unmark({done:()=>m.mark(q.value,{done:n=>say(n+' 件を強調しました。')})});q.oninput=update;update()}


結果の見方
前の強調が消えて新しい語だけが目立つ。
同じ語が一段落に2回あれば2箇所が強調される。
以前の装飾を消してから重ねると、検索語の変更が見た目に反映される。


コードの要点
対象の文書要素に mark を適用し、再検索前に unmark する。


仕事で使うとき
検索結果件数も表示すると、結果がない場合と操作前を区別できる。
