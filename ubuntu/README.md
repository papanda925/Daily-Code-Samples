## ターミナルで結果が見えるサンプル（必須）

- **結果が実行したターミナルに表示されればよい。** 毎回のログ保存や再表示機能を必須としない。利用者の依頼なく自動ログを作らない。
- Bashのサンプルを直接貼り付けてもターミナルを終了させない。トップレベルに `exit` を書かず、関数の中で `return` を使用する。
- パッケージ状態と版数、エラー時の説明と終了コードを確認する。秘密情報やAPT配布先など余計な情報は表示しない。
- コードはできるだけ短くし、コメントは初心者が分かる日本語にする。通常・エラー・直接貼り付け・`source` のテストを行う。

参考：[PHPパッケージ状態確認サンプル](./php-package-status/)。
