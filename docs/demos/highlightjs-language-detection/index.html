実装コード
async v=>{css('https://cdn.jsdelivr.net/npm/highlight.js@11.11.1/styles/github.min.css');const {default:h}=await lib('highlight.js@11.11.1');for(const x of [h.highlightAuto(v,['javascript','python','json']),h.highlight(v,{language:'javascript'})]){el('h3',scene,x.language||'判定なし');const c=el('code',panel('pre'));c.className='hljs';c.innerHTML=x.value}say('上は自動判定。下は JavaScript 固定。')}


結果の見方
短い断片では判定が揺れることがある。
言語が同じと判定された場合は、Python風の短文でも比べる。
HTMLのコード表示に利用する場合は、ライブラリーの更新も管理する。


コードの要点
highlightAuto の language を表示し、highlight の言語指定結果と比較する。


仕事で使うとき
ドキュメントの言語が分かる場合は明示する。
読者もコピー先を判断しやすい。
