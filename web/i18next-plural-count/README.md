# 「1件」と「複数件」のメッセージを切り替える｜i18next

件数の表記は、言語によって使う語が変わります。英語と日本語で、同じ1件と2件を表示します。

## 最初に知っておく用語

- **ロケール**は、表示言語や地域の設定です。
- **複数形**は、件数に応じた単語の形です。

## コードの要点

翻訳キーに count を渡し、英語の単数・複数用リソースを分ける。

実装はデモ画面の「実装コード」で確認できます。

## 仕事で使うとき

翻訳キーは文単位で作る。単語をつなぐと語順の違う言語に対応しにくい。
