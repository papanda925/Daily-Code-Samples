ブラウザーの備品メモを部署で絞る｜Dexie.js

ブラウザーに置いた備品台帳から、部署に合う行を取り出します。

データを保存する機能と、項目を絞り込む機能を一緒に試します。

ライブデモ

公開データや検証用のファイルで試してください。

総務で検索する。

次に経理を入れる。

再読み込みして同じ検索を試す。



実装コード
async v=>{const {default:D}=await lib('dexie@4.0.11');const d=new D('DailyCodeInventory');d.version(1).stores({items:'id,department'});try{await d.items.bulkPut([{id:1,department:'総務',name:'端末A'},{id:2,department:'経理',name:'端末B'}]);say(await d.items.where('department').equals(v).toArray())}finally{d.close()}}


結果の見方
部署に一致する端末が返る。
一覧を全部取り出さず、索引から対象部署を検索できる。
このデモの初期データは起動時に同じ内容で書き込む。
任意の編集が永続化するかの実験には、初期データの投入を分ける。


コードの要点
テーブルを '++id,department' で定義し、where('department').equals('総務').toArray() を実行する。


仕事で使うとき
ブラウザーごとに保存先が分かれる。
共有台帳にするなら別途データの共有が必要になる。
