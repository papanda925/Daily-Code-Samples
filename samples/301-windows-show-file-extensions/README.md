# 301: ファイルの種類が分からないとき、拡張子を表示して見分けたい

> **対象：PC初心者・事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使える

同じ「請求書」という名前に見えるのに、片方はExcel、もう片方はPDFだった――という経験はありませんか。

Windowsでは、初期設定や環境によって `.xlsx`、`.pdf`、`.txt` のような**拡張子（ファイル名の末尾に付く、種類を表す文字）**が見えないことがあります。拡張子を表示すると、ファイルを開く前に種類を判断しやすくなります。

## 何が便利になるか

- `請求書.xlsx` と `請求書.pdf` を名前だけで見分けやすくなる
- `report.csv` と `report.xlsx` の取り違えを減らせる
- 「このファイルは何で開けばよいのか」を判断しやすくなる
- ファイル名を変更するとき、拡張子まで消してしまう事故に気づきやすくなる

## GUIでできる方法

Windows 11では、まずエクスプローラーを開きます。

1. 任意のフォルダーを開く
2. 上部の **表示** を選ぶ
3. **表示** → **ファイル名拡張子** をオンにする
4. ファイル名の末尾に `.txt`、`.xlsx`、`.pdf` などが出ることを確認する

Windows 10では、エクスプローラーの **表示** タブにある **ファイル名拡張子** をオンにします。

この方法が一番簡単です。1台のPCで自分が使うだけなら、まずGUI操作をおすすめします。

## もっと簡単・確実にする方法

複数台のPCで設定を確認するときや、設定手順を人に案内するときは、PowerShellで現在値を確認すると「今どうなっているか」を文字で残せます。

このサンプルの `Show-FileExtensions.ps1` は次の3つの使い方ができます。

- `Status`：現在の設定だけ確認する
- `Show`：拡張子を表示する
- `Hide`：拡張子を非表示に戻す

対象は**現在ログインしている自分のWindowsユーザー設定だけ**です。管理者権限は不要です。

## コピーして試す

PowerShellを開き、このサンプルのフォルダーへ移動して実行します。

```powershell
# まずは変更せず、現在の状態だけ確認します。
.\Show-FileExtensions.ps1 -Mode Status
```

表示する設定へ変える場合は次のようにします。

```powershell
# 拡張子を表示する設定へ変更します。
.\Show-FileExtensions.ps1 -Mode Show
```

元に戻して非表示にする場合はこちらです。

```powershell
# 拡張子を非表示に戻します。
.\Show-FileExtensions.ps1 -Mode Hide
```

PowerShellの実行ポリシーにより `.ps1` が実行できない場合は、無理に設定を変更せず、README内のコードをPowerShellへ貼り付けて試すか、GUI方法だけを使ってください。

## 結果の見方

`-Mode Status` では、たとえば次のように表示されます。

```text
現在の設定: 拡張子を表示
設定値 HideFileExt: 0
```

`HideFileExt` はWindows内部の設定名です。

- `0`：隠さない → 拡張子を表示
- `1`：隠す → 拡張子を非表示

名前が `HideFileExt` なので少し分かりにくいですが、**0のとき表示、1のとき非表示**です。

## 自分で試すテスト

### テスト1：GUIで切り替えてPowerShellで確認する

1. GUIで「ファイル名拡張子」をオンにする
2. `-Mode Status` を実行する
3. `拡張子を表示` と出ることを確認する
4. GUIでオフにする
5. もう一度 `-Mode Status` を実行する

GUI操作とPowerShellの確認結果が連動すれば成功です。

### テスト2：テスト用ファイルで見え方を比べる

自分のドキュメントなど安全な場所に、メモ帳で `test.txt` を1つ作ります。

1. 拡張子を非表示にする
2. エクスプローラーで `test` のように見えることを確認する
3. 拡張子を表示する
4. `test.txt` と見えることを確認する

**ファイル内容やファイル名自体は変わっていない**ことも確認してください。変わるのはエクスプローラーの見せ方だけです。

## うまくいかないとき

設定を変えても表示が変わらない場合は、開いているフォルダーをいったん閉じて開き直してください。会社PCでは組織のポリシーで表示設定が固定されている場合もあります。その場合は会社のIT管理者のルールを優先してください。

PowerShellで `Unknown` と表示された場合は、対象の設定値を取得できなかった状態です。GUIで設定状態を確認してください。

## 少し便利にする

ファイルを受け取ったときは、アイコンだけで判断せず、拡張子も一緒に見る習慣を付けると取り違えを減らせます。特に `csv`、`xlsx`、`xlsm` はExcelで開けても性質が違うため、拡張子表示が役立ちます。

なお、拡張子は「名前の一部」であり、ファイル内容そのものを保証するものではありません。怪しいファイルの安全性確認には、拡張子だけでなく入手元やセキュリティ警告も確認してください。

## 自動化への発展

1台だけならGUIで十分ですが、手順書やPCセットアップではPowerShellを使うと、現在値の確認と設定変更を同じ手順で行えます。

たとえばセットアップ処理では、いきなり変更するのではなく、最初に `Status` を記録し、必要な場合だけ `Show` を実行するようにすると安全です。

このサンプルは**設定変更を自動化する最小例**です。ファイルを削除したり名前を変更したりする処理は含みません。

## 仕組みを知りたい人向け

エクスプローラーのこの設定は、現在のユーザー用レジストリに保存されています。

```text
PowerShell / エクスプローラーGUI
        ↓
現在ユーザーの設定
HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced
        ↓
HideFileExt
        ↓
エクスプローラーの表示
```

`HKCU` は **HKEY_CURRENT_USER** の略で、「今ログインしている自分の設定」を保存する場所です。

このサンプルでは `Set-ItemProperty` を使って `HideFileExt` だけを変更します。PC全体の設定や他のユーザーの設定は変更しません。

### 安全性・PCへの変更

- **管理者権限：不要**
- **PC設定の変更：あり**（現在ユーザーのエクスプローラー表示設定）
- **ファイル内容の変更：なし**
- **ファイル名の変更：なし**
- **元に戻す方法：GUIで「ファイル名拡張子」をオフにする、または `-Mode Hide` を実行する**

初めて試す場合は、最初に `-Mode Status` だけを実行し、現在状態を確認してから変更してください。
