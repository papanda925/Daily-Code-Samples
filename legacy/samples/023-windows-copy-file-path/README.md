# 023: ファイルの場所を正確にコピーして相手へ伝えたい

> **対象：事務職・オフィスワーカー / 所要時間：約5分 / 難しさ：🟢 はじめて**

## こんなときに使えます

「どのフォルダーのどのファイル？」をメールやチャットで正確に伝えたいときに使います。

## 何が便利になりますか？

エクスプローラーの「パスのコピー」でファイルの場所を正確に取得する。

## まず試す方法

エクスプローラーで対象ファイルを選び、「パスのコピー」を使います。WindowsのバージョンによってはShift+右クリックから選べます。

## 結果の見方

貼り付けた文字列にフォルダー名とファイル名が含まれていれば成功です。

## 自分で試してみよう

### テスト1

メモ帳へパスを貼り付けて確認する。

### テスト2

別フォルダーのファイルでパスが変わるか確認する。

## うまくいかないとき

共有先の相手が同じドライブ文字や共有フォルダーへアクセスできるとは限りません。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

問い合わせ対応、障害報告、手順書のファイル指定に便利です。
