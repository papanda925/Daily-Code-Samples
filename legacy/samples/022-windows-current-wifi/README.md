# 022: 今どのWi-Fiにつながっているか詳しく確認したい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

似た名前のWi-Fiが複数あり、本当に目的のネットワークへ接続しているか確認したいときに使います。

## 何が便利になりますか？

Windowsの画面とnetshでSSID・信号・接続情報を確認する。

## まず試す方法

まずタスクバーのネットワーク表示でSSIDを確認します。詳しく見る場合は PowerShell で `netsh wlan show interfaces` を実行します。読み取りだけです。

## 結果の見方

SSID、信号、無線方式など現在の接続情報が表示されれば成功です。

## 自分で試してみよう

### テスト1

Wi-Fi接続中にSSIDを確認する。

### テスト2

別のアクセスポイントへ切り替えた後、表示が変わるか確認する。

## うまくいかないとき

有線LANだけのPCではWi-Fiインターフェースが表示されないことがあります。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

通信トラブル時の一次確認や、社内・来客Wi-Fiの判別に使えます。
