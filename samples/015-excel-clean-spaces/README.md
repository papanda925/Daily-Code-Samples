# 015: Excelで余計な空白や改行をまとめて消したい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

Webやメールから貼り付けた文字に余計なスペースや見えない改行が入り、検索や照合が合わないときに使います。

## 何が便利になりますか？

TRIM・CLEAN・SUBSTITUTEを組み合わせて文字列を整える。

## まず試す方法

日本語の全角スペースも考えるなら `=TRIM(CLEAN(SUBSTITUTE(A2,"　"," ")))` を試します。

## 結果の見方

見た目が整い、XLOOKUPなどの照合にも使いやすい文字列になれば成功です。

## 自分で試してみよう

### テスト1

前後に空白を付けた文字がきれいになるか確認する。

### テスト2

全角スペースを混ぜた文字で結果を比較する。

## うまくいかないとき

TRIMはすべての特殊文字を除去するものではありません。元データを残した列で試します。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

名簿、住所、システム出力CSVの前処理へ応用できます。
