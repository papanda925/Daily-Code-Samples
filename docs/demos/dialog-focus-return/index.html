確認画面を閉じた後のフォーカスを追う｜dialog

確認画面を閉じた後に入力位置を見失うと、キーボード操作が続けにくくなります。

Escやキャンセルの後に焦点がどこへ戻るか調べます。

ライブデモへ

最初に知っておく用語

モーダル
開いている間は背後を操作できない画面
フォーカス
キー入力を受け取る要素

状態遷移図で考える

矢印はフォーカスが移るきっかけです。

閉じ方が違っても、起点へ戻るかを見ます。

図を読み込み中
Mermaidのソースを見る
stateDiagram-v2
    state "起点のボタン" as Launch
    state "確認画面の中" as Dialog
    [*] --> Launch
    Launch --> Dialog: 開く
    Dialog --> Launch: キャンセル
    Dialog --> Launch: Esc

ライブデモ

公開データや検証用のファイルで試してください。

確認画面を開く。

TabとEscを押す。



実装コード
()=>{const d=panel('dialog');el('p',d,'変更を続けますか？');button('キャンセル',()=>d.close('cancel'),d);const b=button('確認画面を開く',()=>d.showModal());d.onclose=()=>say(document.activeElement===b?'起点のボタンに戻りました。':'現在のフォーカス '+document.activeElement.tagName)}


結果の見方
閉じると起点のボタンに戻ることを確認できる。
確認画面を開いた直後に Tab を押す。
どのボタンへ移るかを確認する。
Escで閉じた場合も、クリックした場合と同じ起点を確認する。


コードの要点
showModal() で表示し、キャンセル後に document.activeElement を読む。


仕事で使うとき
フォーム内ではキャンセルでデータが消えないかも確認する。
