既存の候補を表示しながら新しい値も受け付ける｜datalist

部署の入力欄では、よく使う値を候補に出すと便利です。

一覧にない新しい部署を入力できるかも確認します。

ライブデモ

公開データや検証用のファイルで試してください。

総務を選ぶ。

次は候補にない営業と入力して確認する。



実装コード
v=>{const q=field('text'),d=panel('datalist');d.id='departments';for(const x of ['総務','経理'])el('option',d).value=x;q.setAttribute('list',d.id);q.value=v;button('入力を確認',()=>say(q.value))}


結果の見方
どちらも入力した値として取得できる。
ブラウザーによって候補を開く操作や表示が異なる。
入力欄の値が採用されるので、見た目の候補から保存値を推測しない。


コードの要点
input の list 属性を datalist のidへ向け、送信時に入力値を表示する。


仕事で使うとき
部署コードなど候補だけを許可する場合は、入力値を別途検証する。
