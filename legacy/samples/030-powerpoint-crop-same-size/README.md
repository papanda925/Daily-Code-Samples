# 030: PowerPointの複数画像を同じ大きさに揃えたい

> **対象：事務職・オフィスワーカー / 所要時間：約15分 / 難しさ：🟢 はじめて**

## こんなときに使えます

縦横比の違う写真を資料に並べたとき、サイズや形がバラバラになるのを整えたいときに使います。

## 何が便利になりますか？

トリミングとサイズ指定を組み合わせ、写真を同じ見た目で並べる。

## まず試す方法

画像ごとに同じ縦横比へトリミングし、図の形式から同じ高さ・幅を指定します。最後に整列・均等配置を使います。

## 結果の見方

複数画像が同じサイズ・間隔で並べば成功です。

## 自分で試してみよう

### テスト1

縦長と横長の画像2枚を同じ正方形へトリミングする。

### テスト2

3枚を同じ高さにして均等配置する。

## うまくいかないとき

縦横比を無視して幅・高さだけ変えると画像が歪むことがあります。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

人物写真、現場写真、製品一覧などの資料作成に便利です。
