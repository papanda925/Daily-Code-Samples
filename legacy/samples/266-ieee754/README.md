# 266: IEEE 754の浮動小数点をバイト列で眺める

> **短い実験サンプル / 約10〜20分**

## このサンプルで体験すること
短い実験で「IEEE 754の浮動小数点をバイト列で眺める」を体験し、操作前後の状態やログの差を確認する。

## 実行方法
1. `demo.ps1` を読む。
2. 自分のPC・自分のテストデータで実行。
3. 入力や設定を1つだけ変えて再実行し、結果の違いを見る。

## 最小コード
```powershell
foreach($x in 0.1,1.0,-2.5,[double]::NaN){$b=[BitConverter]::GetBytes([double]$x);[pscustomobject]@{Value=$x;Hex=(($b|%{$_.ToString('X2')})-join' ')}}
```

## 見るポイント
- 文字・ファイル・デバイスが、見た目から型・バイト・APIへどう変換されるか。
