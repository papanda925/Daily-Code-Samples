# 027: Wordの長い表で見出し行を各ページに表示したい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

複数ページにまたがる表で、2ページ目以降も列見出しを表示したいときに使います。

## 何が便利になりますか？

表の先頭行をページごとに繰り返して、長い表を読みやすくする。

## まず試す方法

表の先頭行を選び、表レイアウトの「タイトル行の繰り返し」を設定します。

## 結果の見方

表が改ページされたとき、各ページ上部に同じ見出し行が表示されれば成功です。

## 自分で試してみよう

### テスト1

十分な行数の表を作り2ページ目で見出しが出るか確認する。

### テスト2

設定を解除し、2ページ目から見出しが消えるか確認する。

## うまくいかないとき

手動改ページや複雑な表では期待どおりにならないことがあります。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

一覧表、名簿、報告書、点検表などに便利です。
