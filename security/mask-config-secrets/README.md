## まず試す（ダミー設定だけ）

[mask-secrets.sh](mask-secrets.sh) は、指定した入力ファイルを読み、同じ場所へ `.masked` ファイルを**新規に生成**します。実際の秘密情報は使わないでください。

```bash
printf 'api_key=dummy123\nuser=sample\n' > demo.env
bash mask-secrets.sh demo.env
cat demo.env.masked
```

**期待結果（未実行）**：`api_key` の値が `****` として出力され、`user=sample` は残ります。出力先が存在する場合は上書きせず終了コード3となる設計です。元の `demo.env` は変更しません。

## しくみ・重要な制限

awkでよくあるキー名とURL中の資格情報や秘密鍵ブロックを検知します。ただし**完全な秘密情報除去は保証されません**。JSON、複雑な引用、未知のキー名、独自フォーマットなどは検出できない場合があります。`.masked` も自動公開しないで、**人が全文を確認**してから共有します。
