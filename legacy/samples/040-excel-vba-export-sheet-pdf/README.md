# 040: Excelの今見ているシートをPDFで保存したい

> **対象：事務職・オフィスワーカー / 所要時間：約20分 / 難しさ：🟡 ちょっと応用**

## こんなときに使えます

毎回「名前を付けて保存」からPDFを選ぶ作業を短くしたいときに使います。

## 何が便利になりますか？

VBAでアクティブシートを同じフォルダーへPDF出力する。

## まず試す方法

付属VBAは、ブックが保存済みか確認し、現在のシートをブックと同じフォルダーへPDF出力します。最初はコピーしたブックで試します。

このフォルダーには **`ExportActiveSheetToPdf.bas`** も入っています。最初にコードを読み、テスト用データで試してください。

## 結果の見方

シート名を含むPDFが同じフォルダーへ作成されれば成功です。

## 自分で試してみよう

### テスト1

テストシート1枚でPDFが作られるか確認する。

### テスト2

別シートへ切り替え、別名PDFになるか確認する。

## うまくいかないとき

同名PDFが存在する場合の運用や印刷範囲は業務に合わせて調整が必要です。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

月次帳票、請求書、報告書のPDF化へ発展できます。
