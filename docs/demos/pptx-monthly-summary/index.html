定型の月次サマリーをPowerPointで作る｜PptxGenJS

毎月の報告で変わるのが見出しと件数なら、同じ配置を使い回せます。

月名を入れてスライドを一枚生成します。

ライブデモへ

最初に知っておく用語

スライド
プレゼン資料の1画面
テキストボックス
文字を置く枠

カンバン図で考える

列は月次報告の作業段階です。

生成できたら、最後の列の見た目も点検します。

図を読み込み中
Mermaidのソースを見る
kanban
    column1[入力]
        task1[月名と件数を用意]
    column2[生成]
        task2[見出しと件数を配置]
    column3[確認]
        task3[長い見出しのはみ出しを点検]

ライブデモ

公開データや検証用のファイルで試してください。

月名を変えて保存する。

長い見出しも試す。



実装コード
async v=>{const {default:P}=await lib('pptxgenjs@3.12.0');const p=new P(),s=p.addSlide();s.addText(v,{x:.6,y:.7,w:8.5,h:.7,fontSize:24});s.addText('確認済み 18 件',{x:.6,y:1.6,w:8.5,h:.6});save('monthly.pptx',await p.write({outputType:'blob'}));say('見出しと件数を1枚に配置しました。')}


結果の見方
同じ位置に月名と件数が入る。
タイトルを長くして、読みやすい文字サイズが維持されるか確認する。
数値が折り返す場合は、データより先に枠の幅を調べる。


コードの要点
addSlide で1枚を追加します。
addText を使って見出しと件数の位置を指定します。
write でファイルにします。


仕事で使うとき
月次報告を自動化するときは桁が増えた値と長い見出しをテストする。
