# 301: ファイルの種類が分からないとき、拡張子を表示して見分けたい

> **対象：PC初心者・事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## このサンプルで体験すること

同じ「請求書」という名前に見えるのに、片方はExcel、もう片方はPDFだった――という場面を想定します。

Windowsでは、`.xlsx`、`.pdf`、`.txt` のような**拡張子（ファイル名の末尾に付く、種類を表す文字）**を隠して表示できます。このサンプルでは、GUIで拡張子を表示する方法と、PowerShellで現在の設定を確認・切り替える方法を比べます。

### こんなときに使える

- ExcelとPDFなど、同じ名前のファイルを見分けたい
- `csv` と `xlsx` の取り違えを減らしたい
- 「このファイルは何で開けばよいのか」を判断しやすくしたい
- PCセットアップ時に拡張子表示の設定を確認したい

### 何が便利になるか

- `請求書.xlsx` と `請求書.pdf` を名前だけで見分けやすくなる
- `report.csv` と `report.xlsx` の取り違えを減らせる
- ファイルを開く前に種類を判断しやすくなる
- 設定状態をPowerShellの文字列として確認できる

## なぜこの方法を使うのか

1台のPCで自分が使うだけなら、エクスプローラーのGUI操作が最も簡単です。

一方、PCセットアップや手順確認では「今は表示なのか非表示なのか」を文字で確認できると便利です。そのため、このサンプルではGUIを基本にしつつ、PowerShellで現在値を確認し、必要な場合だけ設定を変更できるようにします。

専門用語では、この設定は**レジストリ（Windowsが設定値を保存する場所）**に保存されています。ただし、最初はレジストリを意識せず、GUIから試して構いません。

## GUIでできる方法

Windows 11では次のように操作します。

1. エクスプローラーで任意のフォルダーを開く
2. 上部の **表示** を選ぶ
3. **表示** → **ファイル名拡張子** をオンにする
4. ファイル名の末尾に `.txt`、`.xlsx`、`.pdf` などが出ることを確認する

Windows 10では、エクスプローラーの **表示** タブにある **ファイル名拡張子** をオンにします。

まずはこの方法だけ覚えれば十分です。

## もっと簡単・確実にする方法

複数台のPCで同じ確認をするときや、設定手順を記録したいときはPowerShellが便利です。

`Show-FileExtensions.ps1` は次の3つの使い方を用意しています。

- `Status`：現在の設定だけ確認
- `Show`：拡張子を表示
- `Hide`：拡張子を非表示に戻す

対象は**現在ログインしている自分のWindowsユーザー設定だけ**です。管理者権限は不要です。

## 実行前に確認すること

- **管理者権限：不要**
- **PC設定の変更：あり**（`Show` / `Hide` 実行時のみ）
- **ファイル内容の変更：なし**
- **ファイル名の変更：なし**
- **想定PowerShell：Windows PowerShell 5.1 / PowerShell 7**
- 会社PCでは組織のルールやポリシーを優先する
- 最初は `Status` だけ実行すれば設定変更は発生しない

元に戻すには、GUIで「ファイル名拡張子」をオフにするか、`-Mode Hide` を実行します。

## 実行手順

1. GUIで現在のファイル名の見え方を確認する
2. PowerShellを開く
3. このサンプルのフォルダーへ移動する
4. `-Mode Status` で現在設定を確認する
5. 必要なら `-Mode Show` で表示する
6. エクスプローラーで拡張子が見えるか確認する
7. テスト後に元へ戻したい場合は `-Mode Hide` を実行する

## コピーして試す

まずは変更せず、現在の状態だけ確認します。

```powershell
.\Show-FileExtensions.ps1 -Mode Status
```

表示する設定へ変える場合はこちらです。

```powershell
# 拡張子を表示する設定へ変更します。
.\Show-FileExtensions.ps1 -Mode Show
```

元に戻して非表示にする場合はこちらです。

```powershell
# 拡張子を非表示に戻します。
.\Show-FileExtensions.ps1 -Mode Hide
```

PowerShellの実行ポリシーにより `.ps1` が実行できない場合は、無理に設定を変更せずGUI方法だけを使ってください。

## コードの流れ

### 1. 現在の設定保存場所を決める

現在ユーザー用の次の場所を読みます。

```text
HKCU\Software\Microsoft\Windows\CurrentVersion\Explorer\Advanced
```

`HKCU` は **HKEY_CURRENT_USER** の略で、「今ログインしている自分の設定」です。

### 2. HideFileExt の値を読む

`HideFileExt` は「拡張子を隠すか」を表す値です。

- `0`：隠さない → 拡張子を表示
- `1`：隠す → 拡張子を非表示

名前と表示状態が逆に見えるので、コードでは人が読める「拡張子を表示」「拡張子を非表示」に変換して出力します。

### 3. 必要な場合だけ1つの設定値を変更する

`Show` では `0`、`Hide` では `1` を保存します。ファイルそのものには触れません。

### 4. 変更前後を表示する

設定を変える場合は、変更前と変更後を表示します。何が変わったか自分で確認できるようにするためです。

## 結果の見方

`-Mode Status` では、たとえば次のように表示されます。

```text
現在の設定: 拡張子を表示
設定値 HideFileExt: 0
```

`-Mode Show` または `-Mode Hide` では、変更前と変更後が表示されます。

```text
変更前: 拡張子を非表示
変更後: 拡張子を表示
```

エクスプローラーの見た目がすぐ変わらない場合は、フォルダーを閉じて開き直して確認します。

## 自分で試してみよう

### テスト1

**GUIで切り替えてPowerShellの結果が変わるか確認します。**

1. GUIで「ファイル名拡張子」をオンにする
2. `-Mode Status` を実行する
3. `拡張子を表示` と出ることを確認する
4. GUIでオフにする
5. もう一度 `-Mode Status` を実行する
6. `拡張子を非表示` と出れば成功

### テスト2

**テスト用ファイルで見え方だけが変わることを確認します。**

自分のドキュメントなど安全な場所に、メモ帳で `test.txt` を1つ作ります。

1. 拡張子を非表示にする
2. エクスプローラーで `test` のように見えることを確認する
3. 拡張子を表示する
4. `test.txt` と見えることを確認する
5. ファイル内容が変わっていないことを確認する

変わるのはエクスプローラーの見せ方だけです。

## うまくいかないとき

設定を変えても表示が変わらない場合は、開いているフォルダーを閉じて開き直してください。

会社PCでは組織のポリシーで表示設定が固定されている場合があります。その場合は会社のIT管理者のルールを優先してください。

PowerShellで `Unknown` と表示された場合は、対象の設定値を取得できなかった状態です。GUIで設定状態を確認してください。

`.ps1` を実行できない場合は、実行ポリシーを安易に変更せず、GUI操作だけで試す方法が安全です。

## 少し便利にする

ファイルを受け取ったときは、アイコンだけで判断せず拡張子も見る習慣を付けると、取り違えを減らせます。

特に `csv`、`xlsx`、`xlsm` はExcelで開けても性質が異なります。また、拡張子は名前の一部であり、ファイル内容そのものを保証するものではありません。怪しいファイルでは、入手元やWindowsのセキュリティ警告も確認してください。

## 自動化への発展

1台だけならGUIで十分ですが、PCセットアップ手順ではPowerShellを使うと、現在値の確認と設定変更を同じ手順にできます。

安全に自動化するなら、いきなり変更するのではなく、まず `Status` を記録し、必要な場合だけ `Show` を実行する流れにします。

このサンプルは**設定変更を自動化する最小例**です。ファイル削除やファイル名変更は行いません。

## 安全性・PCへの変更

- **管理者権限：不要**
- **PC設定の変更：あり**（現在ユーザーのエクスプローラー表示設定）
- **変更対象：`HideFileExt` という1つの設定値**
- **ファイル内容の変更：なし**
- **ファイル名の変更：なし**
- **元に戻す方法：GUIで「ファイル名拡張子」をオフにする、または `-Mode Hide` を実行する**

自分の元の設定へ正確に戻したい場合は、最初に `-Mode Status` を実行して状態を覚えておいてください。

## 仕組みを知りたい人向け

GUI操作とPowerShellは、最終的には同じユーザー設定を見ています。

## 今回触っている技術の層

```text
エクスプローラーGUI / PowerShell
        ↓
現在ユーザーの設定（HKCU）
        ↓
Explorer Advanced / HideFileExt
        ↓
Windows エクスプローラーの表示
```

PowerShellでは `Get-ItemProperty` で値を読み、`Set-ItemProperty` で値を書きます。これはWindows設定をスクリプトから確認・変更する基本形の1つです。
