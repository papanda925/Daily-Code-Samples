Daily Code / 49

動画で日本語と英語の字幕を切り替える｜track

一つの動画には、複数の言語の字幕を付けられます。

動画の同じ秒数を使って、字幕だけを切り替えます。

ライブデモへ

最初に知っておく用語

字幕トラック
時刻と字幕を組み合わせたデータ
WebVTT
ブラウザーで使える時刻付き字幕形式

タイムラインで考える

字幕の表示は動画の時刻に沿って進みます。

1秒付近で言語の違いを確認できます。

図を読み込み中
Mermaidのソースを見る
timeline
    title 字幕の表示区間
    開始 : 字幕なし
    1.0秒 : 日英から選んだ字幕を表示
    3.2秒 : 字幕が消える

ライブデモ

公開データや検証用のファイルで試してください。

日本語、英語、オフを順に選ぶ。

2秒付近の表示を見比べる。



実装コード
async()=>{const c=panel('canvas');c.width=320;c.height=180;const g=c.getContext('2d');const v=panel('video');v.controls=true;v.muted=true;v.playsInline=true;if(!c.captureStream||!window.MediaRecorder)throw Error('この環境では動画生成に対応していません。');const stream=c.captureStream(12),r=new MediaRecorder(stream),parts=[],urls=[];const done=new Promise(resolve=>r.onstop=resolve);r.ondataavailable=e=>parts.push(e.data);r.start();let frame=0;const draw=()=>{g.fillStyle='#173a32';g.fillRect(0,0,320,180);g.fillStyle='white';g.font='24px sans-serif';g.fillText('Daily Code '+Math.floor(frame/12),30,90);frame++};draw();const tick=setInterval(draw,83);await new Promise(resolve=>setTimeout(resolve,3300));clearInterval(tick);r.stop();await done;stream.getTracks().forEach(t=>t.stop());const url=(data,type)=>{const u=URL.createObjectURL(new Blob(data,{type}));urls.push(u);return u};v.src=url(parts,r.mimeType);c.hidden=true;const tracks=['ja','en'].map((l,i)=>{const t=el('track',v);t.kind='subtitles';t.srclang=l;t.label=i?'English':'日本語';t.src=url(['WEBVTT\n\n00:00:01.000 --> 00:00:03.200\n'+(i?'Sample caption':'字幕の見本')+'\n'],'text/vtt');return t});for(const [i,label] of ['日本語','English','字幕オフ'].entries())button(label,()=>{tracks.forEach((t,j)=>t.track.mode=i===j?'showing':'disabled');v.currentTime=1.3;return v.play()});cleanup=()=>urls.forEach(u=>URL.revokeObjectURL(u));say('字幕ボタンを選んで再生してください。')}


結果の見方
選んだ言語の字幕だけが表示される。
同じタイミングで言語だけを切り替えて比べる。
選択メニューがない場合は、デモ内の字幕ボタンからも切り替えられる。


コードの要点
track の kind、srclang、label を指定し、動画の字幕メニューから選ぶ。


仕事で使うとき
公開前に実動画と字幕の時刻を合わせる。
