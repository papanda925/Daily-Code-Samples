スクロールでカードの見え方を測ろう

このデモについて
青い枠の中でスクロールすると、カードが25%または75%見えたときに表示が変わります。架空データのみ・ログイン不要です。

まず試す

  1. 下の枠内をスクロールして、緑色になるカードを見る。
  2. 「可視率の条件」を25%から75%へ変更する。
  3. 「観察停止」を押してスクロールし、表示が固定されることを比べる。「観察再開」で戻せます。
