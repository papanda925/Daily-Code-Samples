# 036: OneDriveで上書き前のファイルに戻したい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

ExcelやWordを上書きしてしまい、少し前の内容へ戻したいときに使います。

## 何が便利になりますか？

バージョン履歴から過去版を確認し、必要に応じて復元する。

## まず試す方法

OneDrive上のファイルから「バージョン履歴」を開き、日時と更新者を確認します。大切なファイルはまず過去版を開いて内容を確認します。

## 結果の見方

過去の版を表示でき、必要な版を選べる状態になれば成功です。

## 自分で試してみよう

### テスト1

テストファイルを2回更新して履歴が増えるか確認する。

### テスト2

1つ前の版を開き、内容の違いを確認する。

## うまくいかないとき

組織設定や保存場所によって履歴の保持期間・利用可否が異なります。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

共同編集ファイルの誤更新、差し戻し、変更確認に役立ちます。
