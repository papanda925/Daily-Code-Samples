休業日を予約の候補から外す｜flatpickr

窓口が土日に休むなら、予約フォームで土日を候補から外せます。

金曜と土曜を順に選び、入力欄の違いを確認します。

ライブデモ

カレンダーで金曜と土曜を押す。

入力欄が更新される日を確認する。



実装コード
async()=>{css('https://cdn.jsdelivr.net/npm/flatpickr@4.6.13/dist/flatpickr.min.css');const {default:F}=await lib('flatpickr@4.6.13');const f=F(field('text'),{inline:true,disable:[x=>x.getDay()===0||x.getDay()===6],onChange:(_,s)=>say(s)});cleanup=()=>f.destroy()}


結果の見方
土日は選べない。
休日の範囲は地域や運用で違う。
土日だけで決められない場合は、祝日や臨時休業日も受付の条件へ追加する。


コードの要点
disable に土日を返す関数を指定する。


仕事で使うとき
予約受付側でも休業日を検証する。
クライアントのカレンダーは入力を助ける役割を持つ。
