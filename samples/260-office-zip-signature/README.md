# 260: XLSX・DOCX・PPTXの先頭がZIP系であることを確認する

> **短い実験サンプル / 約10〜20分**

## このサンプルで体験すること
短い実験で「XLSX・DOCX・PPTXの先頭がZIP系であることを確認する」を体験し、操作前後の状態やログの差を確認する。

## 実行方法
1. `demo.ps1` を読む。
2. 自分のPC・自分のテストデータで実行。
3. 入力や設定を1つだけ変えて再実行し、結果の違いを見る。

## 最小コード
```powershell
param([string]$Path);if(!$Path){"自分のxlsx/docx/pptxを-Path指定";return};$b=[IO.File]::ReadAllBytes($Path);($b[0..3]|%{$_.ToString('X2')})-join' '
```

## 見るポイント
- 文字・ファイル・デバイスが、見た目から型・バイト・APIへどう変換されるか。

- 古い仕組みが現在のシステムの基礎としてどこに残っているか。
