リッチテキストの装飾をDeltaで観察する｜Quill

文章の一部を太字にすると、見た目のほかに内部のデータも変わります。

書式を付けた範囲がどう記録されるかを観察します。

ライブデモへ

最初に知っておく用語

リッチテキスト
書式を含む文章
Delta
Quillが文章と書式を表す形式

処理のフローチャートで考える

左から右に読みます。

「太字の範囲」が変わると「Delta」にどう影響するかを予想します。

図を読み込み中

ライブデモ

公開データや検証用のファイルで試してください。

文字を選んで太字にする。

出力の attributes を探す。



実装コード
async v=>{css('https://cdn.jsdelivr.net/npm/quill@2.0.3/dist/quill.snow.css');const {default:Q}=await lib('quill@2.0.3');const q=new Q(panel(),{theme:'snow',modules:{toolbar:[['bold']]}});const update=()=>say(q.getContents());q.setText(v);q.on('text-change',update);update()}


結果の見方
太字の区間に属性が付く。
最後の改行も記録される。
一部だけ太字にすると、書式付きと書式なしの区間が分かれる。
文章の差分を扱うときは改行も一つの操作として読む。


コードの要点
getContents() の値をJSON表示し、装飾前後を比べる。


仕事で使うとき
出力の形式を決めるときは、あとで編集を再開する要件も考える。
