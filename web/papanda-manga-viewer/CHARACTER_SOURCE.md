# papanda925 Character Source

このサンプルで使用する Papanda は、ChatGPT との制作で確定した **papanda925 Character Sheet v1** を正本として描き直しています。

## 固定する特徴

- 顔・おなか: クリーム系 `#FFF8F0`
- 耳・目のまわり・手足: ダークブラウン系 `#4A3425`
- 目・鼻: `#222222`
- ほっぺ: `#FFD7C2`
- 背景アクセント: `#E6F3FE`
- 顔は真円にせず、少し横長で柔らかい輪郭
- 大きめのツヤのある目
- 小さな口
- 薄いピンクのほっぺ
- 2〜3頭身のアニメ調・やさしい雰囲気

横向き4ページ版とスマホ縦読み版は、同じキャラクター基準で統一します。
