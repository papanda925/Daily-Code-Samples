# 031: PowerPointのファイルサイズを小さくしたい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

写真を多く貼ったPowerPointが重くなり、メール添付や共有がしづらいときに使います。

## 何が便利になりますか？

画像の圧縮を使い、メール送付しやすい資料サイズへ調整する。

## まず試す方法

画像を選択し「図の圧縮」から用途に合う解像度を選びます。元画像が必要な場合は必ず別ファイルを残します。

## 結果の見方

保存後のファイルサイズが小さくなり、見た目が用途に耐えれば成功です。

## 自分で試してみよう

### テスト1

コピーしたPPTXで圧縮前後のファイルサイズを比較する。

### テスト2

異なる解像度設定で画像の見え方を比べる。

## うまくいかないとき

圧縮後に元画質へ完全に戻せない場合があります。必ずコピーで試します。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

会議資料、写真報告書、メール添付資料の軽量化に使えます。
