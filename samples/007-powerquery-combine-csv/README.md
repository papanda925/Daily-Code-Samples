# 007: 同じ形式のCSVをまとめて1つの表にしたい

> **対象：Excel利用者・事務職 / 所要時間：約20分 / 難しさ：🟡 ちょっと応用**

## こんなときに使えます

毎日・毎月届くCSVを開いて、1つのExcelへコピー＆貼り付けしているときに使います。

## 何が便利になりますか？

CSVを決めたフォルダーへ置き、Power Queryを更新するだけでまとめられる形へ発展できます。

「10ファイルなら10回コピー」という作業を減らせます。

## まずは画面操作でやってみる

Excelの「データ」タブから、フォルダーをデータソースにするPower Queryの取り込み方法を利用できます。

フォルダーを指定し、対象ファイルを確認して、結合・変換へ進みます。

## Mコードで仕組みを見る

このフォルダーの `CombineCsv.m` は、Power Queryが内部で行う処理を小さくした学習例です。

最初のフォルダーパスを自分のテスト用フォルダーへ変更して試します。

## 自分で試してみよう

### テスト1：同じ列のCSVを2つ作る

同じ見出しを持つCSVを2つ用意し、1つの表へまとまるか確認します。

### テスト2：CSVを1つ増やす

同じ形式の3つ目のCSVをフォルダーへ追加し、更新後に行が増えるか確認します。

## うまくいかないとき

CSVごとに列名や列数が違うと、想定どおりに結合できない場合があります。

文字コード、区切り文字、見出し行も確認します。

## 注意点

最初はコピーしたテストデータで試してください。元ファイルの形式がばらばらな業務では、結合前に整形ルールを決める必要があります。
