# 033: Outlookでメールを指定した時刻に送信したい

> **対象：事務職・オフィスワーカー / 所要時間：約10分 / 難しさ：🟢 はじめて**

## こんなときに使えます

夜に作ったメールを翌朝に送りたい、決まった時刻に案内を出したいときに使います。

## 何が便利になりますか？

予約送信・配信タイミングを使い、作成したメールを後で送る。

## まず試す方法

新しいOutlookでは送信ボタンの選択肢から予約送信、クラシックOutlookでは配信タイミングの指定を使える場合があります。自分宛てのテストメールで試します。

## 結果の見方

指定時刻までは送信されず、その後に届けば成功です。

## 自分で試してみよう

### テスト1

5〜10分後を指定して自分宛てに送る。

### テスト2

予約をキャンセル・編集できるか確認する。

## うまくいかないとき

PCやOutlookの状態、組織設定によって動作条件が異なることがあります。

## 注意点

大切な業務データでは、最初にコピーやテスト用データで動作を確認してください。管理者権限が必要な操作はこのサンプルでは前提にしていません。

## もう少し便利にする

勤務時間外に作成した連絡の送信タイミング調整に使えます。
