## コードサンプルの結果を確実に確認する（必須）

Ubuntu/Bashサンプルは、**結果が表示・再確認できない状態で納品しない**。シェル全体を対話ターミナルに貼り付ける場合を考慮し、トップレベルに `exit` を置かない。終了コードは関数やサブシェルの戻り値で返す。GUI端末が実行終了後に閉じても、**成功・失敗の標準出力と診断情報、終了コードをユーザー専用ファイルに保存**して再表示方法を明記する。情報漏えいにつながる機密情報はログへ記録しない。テストでは正常終了、異常終了、直接貼付、source、ログ再表示を確認する。

実装例：[PHPパッケージ状態確認サンプル](./php-package-status/)。
