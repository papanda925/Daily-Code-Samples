API障害時の画面表示を本番に触らず確認する｜Mock Service Worker

APIが止まったときの案内は、原因で変える必要があります。

正常、権限不足、一時停止の応答を作り、画面に出す文を確かめます。

ライブデモ

実装コード
async v=>{const status=Number(v);if(![200,403,503].includes(status))throw Error('200、403、503から選んでください');const payload=status===200?['資料A','資料B']:{message:status===403?'利用権限を確認してください。':'時間をおいて試してください。'};const display=async(response,mode)=>say({方式:mode,status:response.status,結果:await response.json()});await display(Response.json(payload,{status}),'擬似応答から案内を試す');button('MSWで試す（設定後）',async()=>{const script=new URL('./mockServiceWorker.js',location.href);const check=await fetch(script);if(!check.ok){say('READMEの手順でMSWを設定してください。');return}const [msw,browser]=await Promise.all([lib('msw@2.7.0'),lib('msw@2.7.0/browser')]);const uri=new URL('./demo-api/items',location.href);const worker=browser.setupWorker(msw.http.get(uri.href,()=>msw.HttpResponse.json(payload,{status})));await worker.start({serviceWorker:{url:script.href},quiet:true,onUnhandledRequest:'bypass'});try{await display(await fetch(uri),'MSWが通信を受け止める')}finally{worker.stop()}})}


結果の見方
成功、権限の不足、一時的な停止を分けて表示する。
403 は権限の案内へ誘導する。
503 は時間を置く案内を出す。
同じ「エラー」でまとめると利用者は次の操作を選びにくい。


コードの要点
対応する応答からブラウザー標準の Response を作り、案内の分岐を試します。
MSW を使う場合は、案内を分ける処理はそのままに、擬似応答を返す部分をハンドラーに置き換えます。


仕事で使うとき
実環境へ接続する前に、異常時の案内と再試行の導線を確認する。
