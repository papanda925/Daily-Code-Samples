# papanda925 Character Source

このサンプルで使用する Papanda は、ChatGPT との制作で確定した **papanda925 Character Sheet v1** を正本として描き直しています。

## 正本画像

- Repository image: [`assets/papanda925-character-sheet-v1.png`](./assets/papanda925-character-sheet-v1.png)
- GitHub Pages: https://papanda925.github.io/Daily-Code-Samples/assets/papanda925-character-sheet-v1.png

今後の Papanda 画像生成・マンガ・アイキャッチでは、この画像を**最優先のキャラクター参照**として扱います。テーマ、服装、小物、背景、ポーズは変えても、顔立ち・配色・体型・目・ほっぺ・全体のかわいらしいアニメ調は正本に合わせます。

## 固定する特徴

- 顔・おなか: クリーム系 `#FFF8F0`
- 耳・目のまわり・手足: ダークブラウン系 `#4A3425`
- 目・鼻: `#222222`
- ほっぺ: `#FFD7C2`
- 背景アクセント: `#E6F3FE`
- 顔は真円にせず、少し横長で柔らかい輪郭
- 大きめのツヤのある目
- 小さな口
- 薄いピンクのほっぺ
- 2〜3頭身のアニメ調・やさしい雰囲気

## 基本ポーズ・表情

Character Sheet v1 の次の要素を基準にします。

- 正面
- ななめ
- よこ
- 考える
- 驚く
- 説明する・うれしい
- PC作業（ブログ・調べもの）

横向き4ページ版、スマホ縦読み版、今後のブログ用画像も同じキャラクター基準で統一します。
