# Excel UNIQUE + SORTで原本を残したままマスター候補を作る

モダンExcelの動的配列関数 `UNIQUE` と `SORT` を使い、元データを削除せずに重複のない候補一覧を作る教材です。

> 状態: implemented / Excel実機での確認は未実施

## まず試す

A1:A8へ次のデータを貼り付けます。

```text
部署
営業部
総務部
営業部
経理部
総務部
情報システム部
営業部
```

C2へ入力します。

```excel
=SORT(UNIQUE(A2:A8))
```

C2から下へ結果が自動的にスピルします。

期待する候補は次の4件です。

```text
営業部
経理部
情報システム部
総務部
```

## ここを見る

- 元のA列はそのまま残る
- C列には重複のない一覧が出る
- 数式はC2の1セルだけ
- 結果範囲を手入力でコピーする必要がない

「重複の削除」のように原本を書き換える操作とは用途が違います。確認用・候補作成用なら、原本を残す方が安全です。

## 1か所変える

A9へ次を追加します。

```text
人事部
```

そのうえで式の参照範囲だけを `A2:A9` に変えます。

```excel
=SORT(UNIQUE(A2:A9))
```

結果に人事部が1件だけ追加されることを確認します。

## 空欄もある実務データでは

空欄を候補から除きたい場合はFILTERを組み合わせます。

```excel
=SORT(UNIQUE(FILTER(A2:A100,A2:A100<>"")))
```

まずUNIQUE + SORTの動きを理解してからFILTERを追加すると、どの関数が何を担当しているか追いやすくなります。

## テーブル化すると範囲変更を減らせる

元データをExcelテーブルにし、列名を `部署` とした場合は次の形にできます。

```excel
=SORT(UNIQUE(FILTER(Table1[部署],Table1[部署]<>"")))
```

行追加時に固定範囲 `A2:A100` を書き換える必要が減ります。

## 仕事で使うなら

- 部署名・担当者・商品コードの候補一覧
- 入力規則用の候補作成
- 表記揺れを見つける前段階
- 原本を壊さないマスター候補レビュー

UNIQUEは「正しいマスターを自動決定する」関数ではありません。`営業部` と `営業 部` のような表記揺れは別値として残るため、人による確認が必要です。

## もう一歩：件数も見る

候補が何件あるか確認するには次のようにできます。

```excel
=ROWS(UNIQUE(FILTER(A2:A100,A2:A100<>"")))
```

候補一覧と件数を一緒に見ると、前日との差分確認にも使いやすくなります。
