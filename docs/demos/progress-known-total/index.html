Daily Code / 47

全体量が判明した時点で進捗を切り替える｜progress

集計を始めた時点では、全体で何件あるか分からないことがあります。

総件数が判明する前と後で、進捗欄を切り替えます。

ライブデモへ

最初に知っておく用語

不定進捗
全体量が分からない進捗
確定進捗
処理済み量と全体量を示せる進捗

状態遷移図で考える

全体量が分かる瞬間に表示が切り替わります。

その時点で処理件数が0でも確定進捗を表示できます。

図を読み込み中
Mermaidのソースを見る
stateDiagram-v2
    state "全体量が未定" as Unknown
    state "0件以上を処理済み" as Known
    state "完了" as Complete
    [*] --> Unknown
    Unknown --> Known: 全体量が10件と判明
    Known --> Complete: 10件処理

ライブデモ

公開データや検証用のファイルで試してください。

未定と 0 と 6 を試す。

表示と件数を比べる。



実装コード
v=>{const p=panel('progress'),q=field('text');p.max=10;p.setAttribute('aria-label','処理の進み具合');q.value=v;const update=()=>{if(q.value.trim()===''||!Number.isFinite(Number(q.value))){p.removeAttribute('value');say('全体量を調査中')}else{p.value=Number(q.value);say(p.position*10+' / 10 件')}};q.oninput=update;update()}


結果の見方
未定と 0/10 は異なる状態になる。
件数が判明した瞬間に進捗を初期化できる。
処理済み件数が増えたら値だけを更新する。


コードの要点
準備時はvalueを外し、件数が分かったら max=10 と現在値を設定する。


仕事で使うとき
全体量が判明するまでは割合を推測で表示しない。
