# NNN: 「やりたいこと」または「観察したいこと」をタイトルにする

> **対象：PC初心者・学生・オフィスワーカー / 所要時間：約15分 / 難しさ：🟡 ちょっと応用**

## このサンプルで体験すること

何を操作し、何の変化を見るサンプルなのかを2〜4文で説明します。

## なぜこの方法を使うのか

GUI、PowerShell、VBA、Win32、WinRT、.NETなどの中から、なぜ今回の方法を選んだのかを説明します。

## 実行前に確認すること

- 管理者権限が必要か
- PC設定を変更するか
- 一時ファイルを作るか
- Windows PowerShell 5.1 / PowerShell 7 のどちらを想定するか
- VBAなら標準モジュール / クラスモジュールのどちらか

## 実行手順

1. コードを読む
2. 実行前の状態を確認する
3. 実行する
4. 1つだけ条件を変える
5. 再実行して差を見る

## コピーして試す

最小コードを掲載します。

## コードの流れ

### 1. 最初に現在状態を取得する

何をしているかだけでなく、なぜ必要なのかを書く。

### 2. 1つだけ操作する

OS・Office・APIのどの層を触っているのかを書く。

### 3. もう一度状態を取得する

差分から何が分かるのかを書く。

## 結果の見方

成功時に何が表示されるか、どこを比較するかを書く。

## 自分で試してみよう

### テスト1

入力・状態を1つ変え、予想する結果を書く。

### テスト2

別の条件を試し、成功・失敗をどう判定するかを書く。

## うまくいかないとき

OSバージョン、PowerShell版、権限、デバイス有無など、初心者がつまずきやすい点を書く。

## 安全性・PCへの変更

読み取りだけなら「PC設定は変更しない」と明記します。
変更する場合は、何が変わるか・元に戻す方法まで書きます。

## 今回触っている技術の層

```text
PowerShell / VBA
      ↓
.NET / COM / WinRT / Win32
      ↓
Windows / Office
      ↓
必要に応じて Hardware / Network
```

## もう少し深掘りする

同じ処理を別API・別言語で行う場合や、関連するOS概念を書く。
